# K 字形设计

应用采用 B「分离结构」的浅底蓝字版本。`scripts/generate-icons.mjs` 定义各尺寸的绘制参数，运行 `npm run icons` 生成 `src-tauri/icons/icon.svg` 和 `src-tauri/icons/icon.ico`。

## 设计原则

字母采用清楚的竖笔与两条斜笔。以笔画连接位置、斜笔角度和内部留白区分候选，控制装饰数量。图形在放大与缩小后均应能识别为 K。

配色使用界面的 #326798 蓝色，外框采用浅灰 #F1F4F7。深色背景展示用于检查边缘与轮廓辨识度。深蓝底、白色字形作为分离式 K 的配色候选。

应用图标按输出尺寸设置主体占比、线宽与间距。竖笔的直边贴合整数像素边界，斜笔保留抗锯齿和圆角线端。小尺寸也保留独立的竖笔与清楚的中心间隙。

Windows ICO 包含 16、20、24、32、36、40、48、64、256px 九种尺寸，各帧在目标尺寸绘制。`k-b-windows.png` 展示实际尺寸，`k-b-pixel-comparison.png` 展示小尺寸优化对比，`k-b-taskbar.png` 为 150% 系统缩放下的任务栏截图。

## 候选

- A：连体几何 K。实心笔画，斜笔连接处靠右，字母结构明确。
- B：分离式 K。竖笔与斜笔之间留出间隙，减少中心交点的拥挤，浅底蓝字为应用采用方案。
- C：圆角线性 K。圆角线端，斜笔与竖笔相接，延续原有线性风格。

## 文件

- `k-directions.png`：三种字形对比，包含浅色和深色背景的小尺寸预览。
- `k-a.png`、`k-b.png`、`k-c.png`：各方案的 256px PNG。
- `k-b-blue.png`：B 方案的深蓝底、白色字形备选版本。
- `k-b-windows.png`：应用 ICO 在浅色、深色背景上的实际尺寸预览。
- `k-b-pixel-comparison.png`：小尺寸优化前后的原尺寸对比与像素放大图。
- `k-b-taskbar.png`：150% 系统缩放下的实际任务栏截图。

这些文件用于视觉评审。应用图标由 `src-tauri/icons/` 中的资源定义。
