# RDP 人工验收

**RDP 实际兼容性待人工验证。** Key Relay 安装在本地 Windows，初始验收客户端为 `mstsc.exe`。远程服务器使用已有的 RDP 会话。

## 准备

1. 在本地启动 Key Relay，并用 Windows 远程桌面连接登录测试服务器。
2. 选择允许键盘输入、限制剪贴板粘贴的测试区域。先使用文本编辑器，确认接收情况后再测试终端和业务程序。
3. 记录本地／远程 Windows 版本、mstsc 版本、窗口／全屏模式、输入法、网络状况、字符间隔和远程接收程序。
4. 记录 RDP “应用 Windows 组合键”设置。快捷键能否在本地注册和触发需要实际验证；按钮回点可独立启动。

## 验收步骤

| 检查项 | 操作 | 期望及记录 |
| --- | --- | --- |
| 按钮启动 | 填写文本，点击远程输入位置，再返回 Key Relay 点击开始 | 激活 RDP 窗口并回点记录位置，逐字比较原文与远程内容 |
| 多显示器与缩放 | 在左侧、上方及不同缩放副屏中点击远程输入位置，再通过按钮启动 | 回点物理坐标一致，记录显示器排列、缩放与坐标 |
| 目标失效 | 记录后移动、最小化或调整 RDP 窗口，改变相关显示配置 | 提示重新选择，发送字符数为零 |
| 远程布局 | 滚动远程页面或移动控件后重新点击输入位置 | 使用新的点击点，工具只校验本地窗口与显示几何 |
| 快捷键启动 | 点击远程输入位置，分别在 RDP 和 Key Relay 前台按选定组合并完全释放 | 与按钮共用目标回点后发送，记录窗口／全屏模式差异 |
| 中文与输入法 | 分别使用本地及远程中文／英文输入法状态 | 记录实际输出、候选框和重复／缺失字符 |
| 换行 | 分别准备 CRLF 和 LF 两种多行文本 | 每个换行对应一次 Enter，记录终端提交和编辑器换行行为 |
| 制表符 | 在纯文本编辑器和表单分别测试 Tab | 对应目标的插入或切换控件行为 |
| 空白与组合字符 | 测试空格、空行、表情、组合重音 | 空白按原内容处理；记录组合字符实际兼容性 |
| 输入速度 | 以 50 毫秒开始，测试 10／100／500／1,000 毫秒 | 记录可完整接收的设置和网络条件 |
| 鼠标移动 | 发送长文本时移动或滚动 | 继续发送 |
| 普通键盘操作 | 输入期间使用普通字符、方向键、修饰键及无关功能键 | 继续发送，原有按键效果生效，记录人工内容与自动输入混合情况 |
| 人工中止 | 分别按 Esc 或点击远程区域，并检查目标激活（含等待释放）和输入阶段 | Esc 结束各阶段任务；鼠标按下结束目标激活和输入阶段；中止操作保留正常效果 |
| 无关虚拟键状态 | 如果本地系统报告 F22 持续按下，测试按钮及快捷键启动 | 修饰键、鼠标按钮及所选启动功能键按规则释放后正常发送 |
| 已提交事件 | 中止后继续观察远程内容 | 区分中止前已提交的延迟事件与新增发送 |
| 再次启动 | 完全释放快捷键后重新按下 | 从原文开头发送 |
| 窗口状态 | 最小化 Key Relay，分别测试 RDP 窗口／全屏 | 后台任务与状态恢复正常 |
| 置顶与焦点 | 开启图钉后选择 RDP 输入位置，分别测试窗口／全屏 | 记录工具显示层级，确认远程目标获得键盘焦点并接收输入 |
| 置顶操作与中止 | 输入中点击禁用图钉，释放后再次独立点击 | 首次点击只中止，置顶状态保持；第二次点击切换置顶 |
| 权限 | 记录本地工具与 mstsc 的完整性级别，分别测试远程普通／高权限目标 | 以实际接收结果记录，远程提升权限本身不表示本地工具需要提升 |
| 剪贴板 | 比较发送前后本地及远程剪贴板 | Key Relay 保持剪贴板内容 |

Enter 可能提交命令或表单。测试文本应放在专门准备的接收区域。自动完成状态代表本地提交结束，远程完整性以逐字比较为依据。
