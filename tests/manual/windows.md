# Windows 人工验收

## 自动验证范围

本地自动测试覆盖文本转换、编辑历史、任务状态、快捷键按键周期、参数校验、旧设置读取、负坐标换算和响应式布局。用户目录测试验证 `.key-relay`、文件缺失默认值、原配置文件保留及测试目录覆盖。文本存储测试使用临时目录和真实磁盘，覆盖草稿与保存选项、100 条历史上限、相邻去重、删除撤销顺序、原子保存、读取失败保护、写入重试及文件独占。浏览器测试使用模拟 Tauri 命令和 localStorage，覆盖重载恢复、全文查看、独立恢复与原生撤销重做、搜索及滚动位置保留、历史管理、任务保护和页面布局。

受控 Win32 接收窗口验证 SendInput、Unicode、Enter、Tab、表情、输入中止与钩子卸载。独立接收进程验证两种启动入口在工具前台时回点记录窗口，覆盖物理坐标、自身鼠标事件、目标移动失效及自身窗口排除。已有 WebView2 检查覆盖应用启动、无目标按钮禁用、原生启动拒绝、设置页、清理与撤销重做、Rust 通信、快捷键注册、窗口高度、关于页及许可证、链接权限、置顶、最小化、最大化和退出。双进程检查验证重复启动正常退出、原窗口还原聚焦、编辑与页签及置顶保留，以及保存开启时正常退出后的草稿恢复和已有历史加载。保存异常、选项组合及安装后的恢复按以下人工验收。

从普通权限终端构建当前源码后运行 `npm run test:desktop`，使应用具有普通用户完整性级别。测试通过 `KEY_RELAY_TEST_CONFIG_DIR` 使用临时配置目录，保留日常配置；正常启动使用 `%USERPROFILE%\.key-relay\`。已有日常实例运行时，使用独立应用标识构建测试程序，通过 `KEY_RELAY_TEST_EXECUTABLE` 选择产物。测试通过 `KEY_RELAY_TEST_SHORTCUT` 指定临时配置中的快捷键，例如 `F10`；使用当前会话中空闲的组合键，完整输入检查使用专用测试桌面。WebView2 在普通权限下读取调试环境变量；规则见[官方安全说明](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/security#recommended-privilege-level-for-webview2-host-applications)。

浏览器检查覆盖 600px、390px、320px 宽度和 150% 页面缩放。长标题与负坐标详情支持悬停、聚焦及 Esc 收起，显示详情前后主窗口高度一致。原生回点已在两台 100% 缩放显示器验证，检查坐标为 `(2080, 153)` 和 `(160, 160)`，虚拟桌面原点为 `(0, -7)`。负坐标换算另有单元测试。其他显示器排列、混合系统缩放及物理设备完整操作按以下步骤记录。

## 文本与启动

在无实际业务操作的文本编辑器中使用以下样例。第二行的 Tab 可从支持保留制表符的文件粘贴。

```text
Hello 123，中文测试。 !@#$%^&*()
第二行\t第三列 😀 é
```

- [ ] 中文／英文输入法下分别验证中文、英文、数字、常用中英文标点、空格、换行。
- [ ] 将样例中的 `\t` 换成实际 Tab，检查接收程序的键盘语义。
- [ ] CRLF 与 LF 各形成一个 Enter；只有空白的文本仍可发送；空字符串提示填写文本。
- [ ] 尚未记录目标时开始按钮禁用。外部点击后显示单行“已记录输入位置”。悬停或键盘聚焦显示完整窗口标题与坐标，Esc 收起，长标题及负坐标保持主窗口高度。返回工具后，两种入口均激活并回点，目标收到文本。
- [ ] 点击编辑区、清理、清空、设置和标题栏时保留目标。重新点击外部窗口后使用新记录。
- [ ] 在左侧、上方副屏及不同 DPI 显示器记录输入位置，检查负坐标与实际回点一致。
- [ ] 目标窗口移动、缩放、关闭、最小化，以及相关显示器断开、排列或缩放变化后，记录失效，按钮禁用并提示重新选择。
- [ ] 使用置顶测试窗口遮挡记录点，开始后应结束准备，发送字符数为零。
- [ ] 目标激活时按钮显示“取消输入”；准备与发送期间自身模拟点击保持任务运行。默认字符间隔为 50 毫秒。
- [ ] 原文和参数在启动时固定，结束后保留原文。
- [ ] Key Relay 位于前台时，两种入口均可启动。缺少目标时均拒绝发送。准备阶段等待 Ctrl、Alt、Shift、Win、鼠标按钮及本次快捷键功能键释放，持续按住超过 2 秒则取消，同一次按键操作保持中止。
- [ ] 普通字符和无关功能键保持按钮或快捷键启动可用；如果系统报告 F22 持续按下，确认其状态允许正常启动及再次独立启动。
- [ ] 快捷键在 F8／F9／F10 之间切换并验证旧组合释放。用其他程序占用组合时，检查错误和按钮启动。

## 文本清理与编辑历史

以下样例采用转义字符串表示，准备文本时将 `\t` 和 `\n` 分别替换为实际制表符和换行。

- [ ] `"\t第一行  \t\n  第二行 \t\n\n末行  "` 清理后为 `"\t第一行\n  第二行\n\n末行"`。检查缩进、行内空格、空行和末行处理。
- [ ] `" \t\n\t\n"` 清理后为 `"\n\n"`；三个空格清理后为空字符串，字符数为零，清理与清空禁用。
- [ ] `"a\u00a0  "` 清理后保留不换行空格。中文、表情及组合字符保留完整，字符数按 Unicode 标量更新。
- [ ] 清理 `"a  \nb\t"` 后得到 `"a\nb"`。两次 `Ctrl+Z` 依次恢复第一行空格和末行制表符；两次 `Ctrl+Y` 再次完成清理。
- [ ] 已有编辑历史时，清理没有行尾空白的文本，检查提示和原文。随后撤销恢复上一次实际编辑。
- [ ] 清理后继续编辑、清空、撤销和重做，检查文本与字符数同步。
- [ ] 清理后使用全局快捷键发送；撤销清理后立即使用按钮启动。专用接收程序分别得到对应的最新文本。
- [ ] 使用 Tab、Enter 和空格键操作清理及清空，检查焦点、用途提示与可访问名称。

## 中止与连续操作

使用较长文本和较慢字符间隔，避免测试文本形成有效命令。

- [ ] 鼠标移动和滚轮保持输入。
- [ ] 左键、右键、中键、侧键分别中止，保留对应点击效果。
- [ ] 普通字符、修饰键、方向键和无关功能键继续输入，保留实际按键效果。
- [ ] Esc 中止目标激活与输入任务，覆盖启动按键等待释放期间，保留原有效果。
- [ ] 仅释放按键或鼠标按钮保持任务状态。
- [ ] 快捷键在目标激活阶段等待释放时，普通按键保持等待，Esc 或鼠标按下取消准备。
- [ ] 目标激活期间普通按键继续，取消按钮、Esc、启动快捷键或实际鼠标按下取消。
- [ ] 输入中按启动快捷键只中止；完全释放后再次按下才从头启动。
- [ ] 输入中点击禁用的“清理”“清空”“开始输入”或图钉，该次操作只中止并保留原文。随后独立点击正常生效。目标激活期间，文本操作及图钉保持禁用。
- [ ] 输入中关闭程序，确认后续输入停止，快捷键和钩子释放。
