# Windows 人工验收

## 自动验证范围

本地自动测试覆盖文本转换、任务快照与计时、快捷键按键周期、参数校验、原子保存、状态排序、页面交互和响应式布局。受控 Win32 接收窗口验证实际 SendInput、Unicode、Enter、Tab、补充平面字符、外部输入中止及钩子卸载。WebView2 检查覆盖构建后的应用启动、Rust 通信、快捷键注册、窗口高度、关于页版本与离线许可证、外部链接权限、置顶切换、最小化恢复、最大化／还原、重新打开后的普通层级和退出。

浏览器的 150% 页面缩放用于布局检查。Windows 系统缩放与跨显示器行为按以下步骤记录。自动化注入验证原生事件处理，物理设备操作单独验收。

- [ ] 普通用户运行 NSIS 安装包，确认当前用户安装及开始菜单入口。
- [ ] 在缺少 WebView2 的 Windows 测试环境中，确认联网下载、安装及启动；网络不可用时确认错误提示。
- [ ] 验证卸载和再次安装。记录设置是否保留，确认未修改其他应用文件。
- [ ] 验证标题栏拖动、最小化、最大化／还原、关闭，检查按钮和拖动区域互相独立。
- [ ] 图钉开启置顶时背景为蓝色，提示为“取消置顶”；再次点击恢复普通层级。最小化恢复保持置顶，重新打开软件后恢复普通层级。
- [ ] 置顶时点击本地目标程序，确认目标获得键盘焦点，Key Relay 仍保持置顶。
- [ ] 在 100% 与 150% 系统缩放下检查文字和控件；窄窗口为 390px、320px，检查横向内容完整。
- [ ] 增大编辑框、切换页签、显示字段错误，检查页签等高及窗口高度随内容调整。
- [ ] 快速增大再缩小编辑框并清空文本，检查窗口下边缘紧邻底部操作区。连续调整窗口尺寸及最大化还原后，普通窗口高度仍与内容匹配。

## 文本与启动

在无实际业务操作的文本编辑器中使用以下样例。第二行的 Tab 可从支持保留制表符的文件粘贴。

```text
Hello 123，中文测试。 !@#$%^&*()
第二行\t第三列 😀 é
```

- [ ] 中文／英文输入法下分别验证中文、英文、数字、常用中英文标点、空格、换行。
- [ ] 将样例中的 `\t` 换成实际 Tab，检查接收程序的键盘语义。
- [ ] CRLF 与 LF 各形成一个 Enter；只有空白的文本仍可发送；空字符串提示填写文本。
- [ ] 默认 5 秒倒计时、边界 1／60 秒和默认 50 毫秒间隔表现正确。
- [ ] 原文和参数在启动时固定，结束后保留原文。
- [ ] 当前前台为 Key Relay 时阻止开始发送；倒计时结束仍按住键盘或鼠标时取消。
- [ ] 快捷键在 F8／F9／F10 之间切换并验证旧组合释放。用其他程序占用组合时，检查错误和按钮启动。

## 中止与连续操作

使用较长文本和较慢字符间隔，避免测试文本形成有效命令。

- [ ] 鼠标移动和滚轮保持输入。
- [ ] 左键、右键、中键、侧键分别中止，保留对应点击效果。
- [ ] 普通字符、修饰键、功能键分别中止，保留实际按键效果。
- [ ] 仅释放按键或鼠标按钮保持任务状态。
- [ ] 快捷键等待释放阶段，其他真实按键或鼠标按下取消准备。
- [ ] 倒计时期间普通按键继续，Esc 或启动快捷键取消。
- [ ] 输入中按启动快捷键只中止；完全释放后再次按下才从头启动。
- [ ] 输入中点击禁用的“清空”“开始输入”或图钉，该次操作只中止。随后独立点击正常生效。等待快捷键释放和倒计时期间，图钉保持禁用。
- [ ] 输入中关闭程序，确认后续输入停止，快捷键和钩子释放。

## 设置与数据

- [ ] 修改有效参数后立即启动或退出，重新打开检查参数。
- [ ] 空值、小数、越界显示对应错误；恢复默认可以消除字段错误。
- [ ] 使用临时备份验证损坏设置文件提示及恢复默认，检查原始文本未写入配置。
- [ ] 输入前后比较剪贴板内容，保持相同。
- [ ] 在相同及不同完整性级别的本地接收程序上记录结果。权限造成的失败须有可见提示，进度表示本地已提交单元。
