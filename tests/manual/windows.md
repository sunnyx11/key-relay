# Windows 人工验收

## 自动验证范围

本地自动测试覆盖文本转换、编辑历史、任务状态、实时释放判断、参数校验、旧设置读取、负坐标换算和响应式布局。用户目录测试验证 `.key-relay`、文件缺失默认值、原配置文件保留及测试目录覆盖。文本存储测试使用临时目录和真实磁盘，覆盖草稿与保存选项、旧历史兼容、置顶持久化、可配置上限与置顶保护、相邻去重、立即删除、选择清空、全置顶时任务正常提交、原子保存、读取失败保护、写入重试及文件独占。浏览器测试使用模拟 Tauri 命令和 localStorage，覆盖重载恢复、全文查看、独立恢复与原生撤销重做、搜索及滚动位置保留、历史管理、任务保护和页面布局。

受控 Win32 接收窗口测试覆盖 SendInput、Unicode、Enter、Tab、表情、输入中止与钩子卸载。独立接收进程测试覆盖按钮在工具前台时回点记录窗口，覆盖物理坐标、自身鼠标事件、目标移动失效及自身窗口排除。WebView2 测试覆盖应用启动、无目标按钮禁用、原生启动拒绝、设置页、清理与撤销重做、Rust 通信、窗口高度、关于页及许可证、链接权限、置顶、最小化、最大化和退出。双进程测试覆盖重复启动正常退出、原窗口还原聚焦、编辑与页签及置顶保留，以及保存开启时正常退出后的草稿恢复、记录置顶恢复、旧历史加载和清空置顶保护。原生几何测试通过 `cargo test --locked --manifest-path src-tauri/Cargo.toml --test window_state -- --ignored --test-threads=1` 对当前 Release EXE 检查大小和位置保存、单实例唤起、最大化及最小化退出后的普通窗口恢复、默认置顶、屏幕外居中和损坏记录默认值。窗口状态单元测试覆盖多屏负坐标、工作区空隙、混合倍率、边框与尺寸限制。保存异常、混合系统缩放及安装后的恢复按以下人工验收。

从普通权限终端构建当前源码后运行 `npm run test:desktop`，使应用具有普通用户完整性级别。测试通过 `KEY_RELAY_TEST_CONFIG_DIR` 使用临时配置目录，保留日常配置；正常启动使用 `%USERPROFILE%\.key-relay\`。已有日常实例运行时，使用独立应用标识构建测试程序，通过 `KEY_RELAY_TEST_EXECUTABLE` 选择产物。完整输入检查使用专用测试桌面。WebView2 在普通权限下读取调试环境变量；规则见[官方安全说明](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/security#recommended-privilege-level-for-webview2-host-applications)。

浏览器检查覆盖 600px、390px、320px 宽度和 150% 页面缩放。长标题与负坐标详情支持悬停、聚焦及 Esc 收起，显示详情前后主窗口高度一致。负坐标换算另有单元测试。当前构建的 Windows 实时按键查询、目标回点与接收、物理 Esc 和鼠标中止、安装失败后的监听恢复及多显示器交互待按以下步骤验收。RDP 接收按独立验收说明记录。

- [ ] 分别在普通、最大化和最小化状态退出，重开均为普通窗口，保留退出前普通窗口的大小和位置。默认置顶继续有效。

- [ ] 在 100%／150% 混合缩放显示器间移动后退出重开。更改缩放或分辨率后重开，确认逻辑尺寸与完整外框校验正确，首次显示无位置跳动。

- [ ] 编辑框原生拖动柄关闭，文本在内部滚动。调整普通窗口大小、最大化再还原，确认输入、历史列表、历史全文、设置、关于和许可证使用完整可用区域，长内容在内部滚动；底部操作区紧邻窗口下边缘。

- [ ] 显示字段错误、存储提示和长任务错误，确认窗口尺寸保持一致。设置面板与任务状态分别在自身区域滚动，清理、清空和开始按钮完整显示。
- [ ] 底部左侧显示状态，右侧依次显示字符数、清理、清空、开始输入。检查清理与清空为 44×26px、开始按钮为 72×26px，按钮间距为 4px。510px 宽窗口的状态与按钮保持同行；工具窗口内容盒不超过 420px 时，状态在上、操作区在下并靠右。
- [ ] 输入、历史、设置、关于、许可证和更新按钮的文字垂直居中。检查默认、悬停、按下、焦点和禁用状态，清空悬停显示红色反馈；下拉框、只读编辑框及标题栏保持各自配色。

## 文本与启动

在无实际业务操作的文本编辑器中使用以下样例。第二行的 Tab 可从支持保留制表符的文件粘贴。

```text
Hello 123，中文测试。 !@#$%^&*()
第二行\t第三列 😀 é
```

- [ ] 中文／英文输入法下分别验证中文、英文、数字、常用中英文标点、空格、换行。
- [ ] 将样例中的 `\t` 换成实际 Tab，检查接收程序的键盘语义。
- [ ] CRLF 与 LF 各形成一个 Enter；只有空白的文本仍可发送；空字符串提示填写文本。
- [ ] 尚未记录目标时开始按钮禁用。外部点击后显示单行“已记录输入位置”。悬停或键盘聚焦显示完整窗口标题与坐标，Esc 收起，长标题及负坐标保持主窗口高度。返回工具点击开始后激活并回点，目标收到文本。
- [ ] 点击编辑区、清理、清空、设置和标题栏时保留目标。重新点击外部窗口后使用新记录。
- [ ] 在左侧、上方副屏及不同 DPI 显示器记录输入位置，检查负坐标与实际回点一致。
- [ ] 目标窗口移动、缩放、关闭、最小化，以及相关显示器断开、排列或缩放变化后，记录失效，按钮禁用并提示重新选择。
- [ ] 使用置顶测试窗口遮挡记录点，开始后应结束准备，发送字符数为零。
- [ ] 目标激活时按钮显示“取消输入”；准备与发送期间自身模拟点击保持任务运行。默认字符间隔为 50 毫秒。
- [ ] 原文和参数在启动时固定，结束后保留原文。
- [ ] Key Relay 位于前台时通过按钮启动。缺少目标时拒绝发送。准备阶段实时等待 Ctrl、Alt、Shift、Win 和鼠标按钮释放，持续按住超过 2 秒则取消。释放后再次点击开始可正常启动。
- [ ] 分别按住左右修饰键后点击开始，释放后确认任务继续；首字符前重新按住修饰键时取消且发送数量为零。
- [ ] 普通字符及 F8／F9／F10／F22 持续按下时，确认按钮按修饰键和鼠标状态正常启动。
- [ ] 设置页仅有字符间隔等现行设置。空闲时按 Ctrl+Alt+F8/F9/F10 保持空闲；发送时按这些组合继续任务，按键保留系统及目标程序原有效果。
- [ ] 持续运行并多次执行按钮启动、超时、Esc 中止和重新启动。确认系统修饰键和鼠标按钮已释放时，后续任务正常开始。

## 文本清理与编辑历史

以下样例采用转义字符串表示，准备文本时将 `\t` 和 `\n` 分别替换为实际制表符和换行。

- [ ] `"\t第一行  \t\n  第二行 \t\n\n末行  "` 清理后为 `"\t第一行\n  第二行\n\n末行"`。检查缩进、行内空格、空行和末行处理。
- [ ] `" \t\n\t\n"` 清理后为 `"\n\n"`；三个空格清理后为空字符串，字符数为零，清理与清空禁用。
- [ ] `"a\u00a0  "` 清理后保留不换行空格。中文、表情及组合字符保留完整，字符数按 Unicode 标量更新。
- [ ] 清理 `"a  \nb\t"` 后得到 `"a\nb"`。两次 `Ctrl+Z` 依次恢复第一行空格和末行制表符；两次 `Ctrl+Y` 再次完成清理。
- [ ] 已有编辑历史时，清理没有行尾空白的文本，检查提示和原文。随后撤销恢复上一次实际编辑。
- [ ] 清理后继续编辑、清空、撤销和重做，检查文本与字符数同步。
- [ ] 清理后使用按钮发送；撤销清理后立即再次使用按钮启动。专用接收程序分别得到对应的最新文本。
- [ ] 使用 Tab、Enter 和空格键操作清理及清空，检查焦点、用途提示与可访问名称。

## 中止与连续操作

使用较长文本和较慢字符间隔，避免测试文本形成有效命令。

- [ ] 鼠标移动和滚轮保持输入。
- [ ] 左键、右键、中键、侧键分别中止，保留对应点击效果。
- [ ] 普通字符、修饰键、方向键和无关功能键继续输入，保留实际按键效果。
- [ ] Esc 中止目标激活与输入任务，覆盖修饰键等待释放期间，保留原有效果。
- [ ] 仅释放按键或鼠标按钮保持任务状态。
- [ ] 目标激活阶段等待释放时，普通按键保持等待，Esc 或鼠标按下取消准备。
- [ ] 目标激活期间普通按键继续，取消按钮、Esc 或实际鼠标按下取消。
- [ ] Esc 中止后再次点击开始，从原文开头发送。
- [ ] 输入中点击禁用的“清理”“清空”“开始输入”或图钉，该次操作只中止并保留原文。随后独立点击正常生效。目标激活期间，文本操作及图钉保持禁用。
- [ ] 输入中从通知区域选择“退出应用”，确认后续输入停止，钩子释放。

## 草稿与历史

使用专用配置目录和无业务操作的文本接收程序。保存副本包含明文，损坏及权限测试使用可恢复的测试数据。

- [ ] 首次启动两个保存选项均开启。编辑包含缩进、换行、表情的文本，尚未发送即从通知区域退出；重新打开恢复完整文本，任务空闲、目标为空。
- [ ] 编辑、粘贴、清理、清空、Ctrl+Z、Ctrl+Y 和历史恢复后从通知区域退出，检查重启内容与最后编辑一致。清空编辑保留历史。
- [ ] 准备阶段取消保持历史；单字符发送、发送中止和发送失败均保存完整冻结原文。重复最近归档同文仅更新时间并保留置顶，较早相同文本可新增记录。
- [ ] 每条记录在三个操作图标左侧仅显示本地时间，格式为 24 小时制的 `HH:mm`。常规宽度下摘要、时间与操作图标同排并垂直居中。窄窗口下摘要占满首行，时间与图标优先共用下一行；空间不足时继续换行，时间完整显示，横向完整。
- [ ] 历史摘要单行显示，换行按空白展示，超宽显示省略号。搜索省略部分或第三行文本可命中。点击正文显示完整只读文本，换行与缩进保留，编辑内容及历史记录保持原值。返回列表保留搜索、滚动位置并聚焦原正文按钮。
- [ ] 图钉切换记录置顶并显示明确状态；重启保留。置顶组在普通日期组之前，两组各按记录时间倒序。切换保留时间、编号及原文，取消后回到普通组对应时间位置。
- [ ] 最大历史条数默认 100，允许 1～10,000 的整数，点击“保存上限”后生效并在重启后保留。旧 `text.json` 缺少 `maxHistoryEntries` 时按 100 读取。设置为 200 后保存超过 100 条历史，重启后全部保留。
- [ ] 调低上限导致超限时，一次点击“保存上限”即按时间及编号淘汰最旧未置顶记录，全部置顶、当前编辑与草稿保留。小于置顶数量、空值、小数、0 及 10,001 显示字段错误，原上限及历史保留。关闭历史保存后仍可配置上限。
- [ ] 历史上限包含置顶。混合记录新增时淘汰最旧未置顶；达到配置上限且全部置顶时发送新文本，输入正常执行且历史保持原值，独立容量提示持续可见。重复最近归档原文仍可更新时间。提高上限、取消置顶、删除记录或关闭历史保存后收起容量提示。
- [ ] 点击独立“恢复”按钮后切回输入、聚焦且光标位于末尾；一次 Ctrl+Z 恢复替换前内容，一次 Ctrl+Y 重做，提示 3 秒后回到目标提示。底部说明分别描述正文查看和按钮恢复。
- [ ] 每条记录的置顶、恢复和删除均为 26×26px 图标按钮，内部图标为 16×16px、1px 线宽。三个按钮的悬停提示、键盘焦点、禁用状态及点击动作正确。全文在历史面板内部滚动，查看前后窗口等高。
