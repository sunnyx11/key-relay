# Windows 人工验收

## 自动验证范围

本地自动测试覆盖文本转换、编辑历史、草稿同步、任务状态、快捷键按键周期、参数校验、旧设置读取、原子保存、负坐标换算和响应式布局。受控 Win32 接收窗口验证 SendInput、Unicode、Enter、Tab、表情、输入中止与钩子卸载。独立接收进程验证两种启动入口在工具前台时回点记录窗口，覆盖物理坐标、自身鼠标事件、目标移动失效及自身窗口排除。WebView2 检查覆盖应用启动、无目标按钮禁用、原生启动拒绝、设置页、清理与撤销重做、Rust 通信、快捷键注册、窗口高度、关于页及许可证、链接权限、置顶、最小化、最大化和退出。

从普通权限终端运行 `npm run test:desktop`，使应用具有普通用户完整性级别。WebView2 在此权限下读取调试环境变量；规则见[官方安全说明](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/security#recommended-privilege-level-for-webview2-host-applications)。

浏览器检查覆盖 600px、390px、320px 宽度和 150% 页面缩放。长标题与负坐标详情支持悬停、聚焦及 Esc 收起，显示详情前后主窗口高度一致。原生回点已在两台 100% 缩放显示器验证，检查坐标为 `(2080, 153)` 和 `(160, 160)`，虚拟桌面原点为 `(0, -7)`。负坐标换算另有单元测试。其他显示器排列、混合系统缩放及物理设备完整操作按以下步骤记录。

## 安装与窗口

- [ ] 普通用户运行 NSIS 安装包，确认当前用户安装及开始菜单入口。
- [ ] 在缺少 WebView2 的 Windows 测试环境中，确认联网下载、安装及启动；网络不可用时确认错误提示。
- [ ] 验证卸载和再次安装。记录设置是否保留，确认未修改其他应用文件。
- [ ] 验证标题栏拖动、最小化、最大化／还原、关闭，检查按钮和拖动区域互相独立。
- [ ] 图钉开启置顶时背景为蓝色，提示为“取消置顶”；再次点击恢复普通层级。最小化恢复保持置顶，重新打开软件后恢复普通层级。
- [ ] 置顶时点击本地目标程序，确认目标获得键盘焦点，Key Relay 仍保持置顶。
- [ ] 在 100% 与 150% 系统缩放下检查文字和控件；窄窗口为 390px、320px，检查横向内容完整。
- [ ] 增大编辑框、切换页签、显示字段错误，检查页签等高及窗口高度随内容调整。600px 宽度、100% 系统缩放且设置有效时，编辑框最小显示高度为 226px，窗口高度为 364px；设置页末尾的中止说明完整显示。
- [ ] 快速增大再缩小编辑框并清空文本，检查窗口下边缘紧邻底部操作区。连续调整窗口尺寸及最大化还原后，普通窗口高度仍与内容匹配。
- [ ] 底部左侧显示状态，右侧依次显示字符数、清理、清空、开始输入。检查清理与清空为 44×26px、开始按钮为 72×26px，按钮间距为 4px；窄窗口状态在上、操作区在下并靠右。
- [ ] 输入、设置、关于、许可证和更新按钮的文字垂直居中。检查默认、悬停、按下、焦点和禁用状态，清空悬停显示红色反馈；下拉框、只读编辑框及标题栏保持各自配色。

## 应用更新

在隔离 Windows 测试环境使用相同更新公钥签名的两个版本 A、B。正式签名和公开通道的验收与测试密钥构建分别记录。

- [ ] 从 0.1.0 手动安装带更新模块的版本，确认有效输入设置保留、编辑文本清除。
- [ ] 安装版识别正确；将 EXE 复制到其他目录运行，确认只提供手动下载入口。
- [ ] 启动 10 秒后仅检查版本，保持当前页签及焦点；持续运行 24 小时再次检查。关闭自动检查后重启，确认偏好保留。
- [ ] 手动检查当前版本、较低版本和预发布清单，确认保持当前安装；断网、超时和无效清单提示可重试。
- [ ] 新版本先显示版本与说明。确认下载后才请求安装包，下载进度、重复点击和网络失败行为正确。
- [ ] 错误公钥、篡改安装包或签名拒绝进入安装就绪状态；使用正确签名重试成功。
- [ ] 下载期间运行按钮任务和全局快捷键任务，确认输入继续；就绪时活动任务推迟安装。
- [ ] 准备文本并取消安装确认，确认原文保留。切换页签或启动输入任务后，原确认失效。
- [ ] 在确认安装和快捷键启动相邻发生时，核对原生互斥；进入安装准备后两种启动方式均受阻止。
- [ ] 有效设置保存失败时保持原应用和编辑文本，恢复权限后可重试。
- [ ] 安装启动失败时确认快捷键、钩子和按钮任务恢复。资源恢复失败时确认错误信息可见。
- [ ] 完成 A→B，检查旧进程退出、新进程启动、版本更新、设置与更新偏好保留、编辑文本清除。
- [ ] GitHub 草稿公开后从正式端点检查、下载并完成升级，记录安装包 SHA-256、签名公钥标识和版本。

## 文本与启动

在无实际业务操作的文本编辑器中使用以下样例。第二行的 Tab 可从支持保留制表符的文件粘贴。

```text
Hello 123，中文测试。 !@#$%^&*()
第二行\t第三列 😀 é
```

- [ ] 中文／英文输入法下分别验证中文、英文、数字、常用中英文标点、空格、换行。
- [ ] 将样例中的 `\t` 换成实际 Tab，检查接收程序的键盘语义。
- [ ] CRLF 与 LF 各形成一个 Enter；只有空白的文本仍可发送；空字符串提示填写文本。
- [ ] 尚未记录目标时开始按钮禁用。外部点击后显示单行“已记录输入位置”。悬停或键盘聚焦显示完整窗口标题与坐标，Esc 收起，长标题及负坐标保持主窗口高度。返回工具后，两种入口均激活并回点，目标收到文本。
- [ ] 点击编辑区、清理、清空、设置和标题栏时保留目标。重新点击外部窗口后使用新记录。
- [ ] 在左侧、上方副屏及不同 DPI 显示器记录输入位置，检查负坐标与实际回点一致。
- [ ] 目标窗口移动、缩放、关闭、最小化，以及相关显示器断开、排列或缩放变化后，记录失效，按钮禁用并提示重新选择。
- [ ] 使用置顶测试窗口遮挡记录点，开始后应结束准备，发送字符数为零。
- [ ] 目标激活时按钮显示“取消输入”；准备与发送期间自身模拟点击保持任务运行。默认字符间隔为 50 毫秒。
- [ ] 原文和参数在启动时固定，结束后保留原文。
- [ ] Key Relay 位于前台时，两种入口均可启动。缺少目标时均拒绝发送。准备阶段等待 Ctrl、Alt、Shift、Win、鼠标按钮及本次快捷键功能键释放，持续按住超过 2 秒则取消，同一次按键操作保持中止。
- [ ] 普通字符和无关功能键保持按钮或快捷键启动可用；如果系统报告 F22 持续按下，确认其状态允许正常启动及再次独立启动。
- [ ] 快捷键在 F8／F9／F10 之间切换并验证旧组合释放。用其他程序占用组合时，检查错误和按钮启动。

## 文本清理与编辑历史

以下样例采用转义字符串表示，准备文本时将 `\t` 和 `\n` 分别替换为实际制表符和换行。

- [ ] `"\t第一行  \t\n  第二行 \t\n\n末行  "` 清理后为 `"\t第一行\n  第二行\n\n末行"`。检查缩进、行内空格、空行和末行处理。
- [ ] `" \t\n\t\n"` 清理后为 `"\n\n"`；三个空格清理后为空字符串，字符数为零，清理与清空禁用。
- [ ] `"a\u00a0  "` 清理后保留不换行空格。中文、表情及组合字符保留完整，字符数按 Unicode 标量更新。
- [ ] 清理 `"a  \nb\t"` 后得到 `"a\nb"`。两次 `Ctrl+Z` 依次恢复第一行空格和末行制表符；两次 `Ctrl+Y` 再次完成清理。
- [ ] 已有编辑历史时，清理没有行尾空白的文本，检查提示和原文。随后撤销恢复上一次实际编辑。
- [ ] 清理后继续编辑、清空、撤销和重做，检查文本与字符数同步。
- [ ] 清理后使用全局快捷键发送；撤销清理后立即使用按钮启动。专用接收程序分别得到对应的最新文本。
- [ ] 使用 Tab、Enter 和空格键操作清理及清空，检查焦点、用途提示与可访问名称。

## 中止与连续操作

使用较长文本和较慢字符间隔，避免测试文本形成有效命令。

- [ ] 鼠标移动和滚轮保持输入。
- [ ] 左键、右键、中键、侧键分别中止，保留对应点击效果。
- [ ] 普通字符、修饰键、方向键和无关功能键继续输入，保留实际按键效果。
- [ ] Esc 中止目标激活与输入任务，覆盖启动按键等待释放期间，保留原有效果。
- [ ] 仅释放按键或鼠标按钮保持任务状态。
- [ ] 快捷键在目标激活阶段等待释放时，普通按键保持等待，Esc 或鼠标按下取消准备。
- [ ] 目标激活期间普通按键继续，取消按钮、Esc、启动快捷键或实际鼠标按下取消。
- [ ] 输入中按启动快捷键只中止；完全释放后再次按下才从头启动。
- [ ] 输入中点击禁用的“清理”“清空”“开始输入”或图钉，该次操作只中止并保留原文。随后独立点击正常生效。目标激活期间，文本操作及图钉保持禁用。
- [ ] 输入中关闭程序，确认后续输入停止，快捷键和钩子释放。
