# Key Relay

Key Relay 是 Windows 文本自动输入工具，可将准备好的文本作为键盘输入发送到目标窗口，适用于允许键盘输入、限制剪贴板粘贴的 RDP 会话。软件运行在本地，通过现有 RDP 客户端向远程窗口输入。

## 使用方法

支持 Windows 10／11 x64。从 [Releases](https://github.com/sunnyx11/key-relay/releases/latest) 下载并运行安装包，也可使用免安装程序。程序依赖 WebView2，安装包会在缺少运行时时联网安装。

1. 在“输入”页填写或粘贴文本。
2. 点击 Key Relay 外的目标输入位置。工具记录该次点击的屏幕坐标与窗口，输入页显示“已记录输入位置”，悬停或聚焦提示可查看窗口标题与坐标。
3. 返回 Key Relay，点击“开始输入”。目标窗口会被激活并回点，然后开始发送。
4. 输入期间按 `Esc` 或点击鼠标可中止。鼠标移动和普通按键保持输入继续。

也可按下并松开 `Ctrl + Alt + F8` 启动。快捷键和按钮均激活并回点已记录位置，Key Relay 位于前台时也可使用快捷键。设置页可调整字符间隔和启动快捷键，默认字符间隔为 50 毫秒。

- **清理**：删除每行末尾的普通空格和制表符，保留缩进、行内空格及空行。
- **撤销与重做**：清理支持 `Ctrl+Z` 逐行撤销、`Ctrl+Y` 逐行重做；清空和历史恢复支持整体撤销与重做。
- **草稿恢复**：默认保存最新编辑内容，包含未发送修改，重新启动时自动恢复。清空后重启为空，历史保留。
- **历史记录**：实际开始输入时保存完整原文，最近归档的相同内容更新时间。摘要单行省略，支持全文搜索、查看及恢复。图钉置顶在重启后保留，置顶组在普通日期组之前，各组按时间倒序。
- **历史管理**：默认最多保留 100 条，可在“设置 → 文本保存”配置为 1～10,000 条。点击“保存上限”立即生效，调低时清理超限未置顶记录；上限至少等于当前置顶数量。新增时仅淘汰最旧未置顶记录。全部置顶时跳过新增历史并提示，输入任务继续执行。单条删除立即生效；清空需确认，默认保留置顶，可勾选同时删除置顶记录。
- **文本保存**：设置页可分别关闭草稿和历史保存。内容以明文保存在用户数据目录，关闭保存保留已有副本，可手动清除。读取或保存失败时按提示重试。
- **窗口恢复**：正常退出后恢复上次窗口大小和位置。位置超出显示器可用范围时，在主屏居中；最大化或最小化退出后恢复普通窗口。
- **数据目录**：设置、草稿、历史、更新偏好及窗口状态统一保存在 `%USERPROFILE%\.key-relay\`。新目录缺少文件时使用默认设置和空数据，原 Windows 应用配置目录的文件保留原处。
- **单实例**：重复启动会显示已有窗口，最小化时先还原，并保留当前编辑、页签和置顶状态。
- **多显示器**：按物理屏幕坐标回点，支持负坐标及不同缩放比例。窗口移动、最小化或显示配置变化后，按提示重新选择。
- **目标位置**：记录表示点击点。页面滚动、远程布局或控件移动后需要重新点击；记录仅保留在本次运行期间。

换行和制表符分别按 `Enter`、`Tab` 发送，可能提交内容或切换控件，具体效果由目标程序决定。

## 开发

需要 Windows x64、Node.js 24、Rust 1.91.1 或更高版本、Visual Studio C++ 生成工具、Windows SDK 和 WebView2。

```bash
npm ci
npm run desktop
```

仅调试前端界面时可使用 `npm run dev`。

## 打包

构建独立 EXE：

```bash
npm run tauri -- build --no-bundle
```

生成文件位于 `src-tauri/target/release/key-relay.exe`。

生成安装包前，按[更新签名配置](docs/release.md#更新签名配置)准备签名环境变量，然后执行：

```bash
npm run package
```

安装包及更新签名位于 `src-tauri/target/release/bundle/nsis/`。
