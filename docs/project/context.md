# Project 上下文

## 项目背景与用途

key-relay 运行在本地 Windows，将准备好的文本通过模拟键盘输入发送到 RDP 远程服务器。主要场景是远程会话允许键盘输入，但禁用剪贴板粘贴。首个验收客户端为 Windows 远程桌面连接 `mstsc.exe`。

## 系统目标

提供由使用者主动触发的文本输入工具。开始按钮激活并回点记录目标，详细规则及验收示例见[领域需求](../domains/text-input/requirements.md)。

## 主要能力

已识别的业务领域为[文本自动输入](../domains/text-input/overview.md)。首版目标功能包括文本准备、草稿保存与启动恢复、历史全文查看与恢复、按钮启动、顺序发送、人工中止、设置及状态展示。应用按单实例运行，重复启动唤起已有窗口。

## 当前系统状态

仓库包含 Tauri 桌面应用、React 界面、Rust 任务与 Windows 输入模块，以及 [HTML 界面原型](../../prototypes/key-relay.html)。开发、构建、自动测试和安装包入口见 [README](../../README.md)。

仓库包含标签构建与 Release 草稿配置，以及 0.2.1 更新检查、显式下载和确认安装实现。自动验证覆盖组件、发布脚本和原生任务互斥。标签发布、正式签名配置、安装升级和公开通道已通过人工验收；发布操作与附件约定见[版本发布](../release.md)。

Spec 根目录为 `docs/`，导航入口为 `docs/index.md`。需求确认与兼容性验证分别表述。文本处理、草稿及历史存储、任务状态、设置、界面和 Windows 输入具备本地自动验证。WebView2 验证覆盖重复启动唤起、窗口会话保留，以及保存开启时正常退出后的草稿恢复和已有历史加载。保存异常、选项组合及安装升级已通过人工验收。RDP 实际兼容性待专用环境验收。Windows 系统版本、目标程序、安装环境及缩放的验收范围见[Windows 验收说明](../../tests/manual/windows.md)。

## 技术环境与依赖

产品目标运行环境为 Windows。技术职责如下，依赖版本由 `package-lock.json` 和 `src-tauri/Cargo.lock` 固定。

| 技术 | 职责 |
| --- | --- |
| Tauri 2 | 桌面窗口、前后端通信及应用打包 |
| React + TypeScript | 文本编辑、历史恢复、保存设置、按钮、目标激活及任务状态展示 |
| Vite | 前端开发与构建 |
| Rust | 文本持久化、输入任务、目标记录与激活、发送间隔、中止判断及资源释放 |
| Rust `windows` crate | 调用 Windows 原生输入与监听接口 |
| `tauri-plugin-single-instance` | 启动前检查应用实例，重复启动还原、显示并聚焦已有窗口 |
| `tauri-plugin-opener` | 关于页链接的系统浏览器与默认邮件应用调用 |
| `tauri-plugin-updater` | HTTPS 版本检查、下载签名验证及 NSIS 更新安装 |
| `winreg` | 读取当前用户安装记录并结合 EXE 位置识别安装版 |
| WebView2 | Windows 上的界面运行环境 |

- 首版使用 React 自带状态管理，应用范围包含本地桌面界面和 Rust 原生逻辑。
- 支持 Windows 10／11 x64，默认普通权限；采用自定义标题栏。
- 使用当前用户 NSIS 安装程序，缺少 WebView2 时联网安装运行时。
- 仓库内 Spec 维护脚本、前端开发与构建使用 Node.js；版本要求见[版本发布](../release.md#构建与附件)。Rust 原生代码使用 Rust 工具链构建。
- 系统输入、任务调度及通信约束见[领域设计](../domains/text-input/design.md#技术决策与约束)。

## 已知限制

目标程序允许真实键盘输入，并不能证明其接受模拟输入。系统权限和目标程序的输入处理方式会影响实际接收结果，兼容范围需要实现后的验证依据。

首版验收范围：

- 本地 Windows 10、Windows 11 的 64 位桌面环境。
- RDP 远程服务器中的终端、编辑器及业务程序输入区域。
- 本地测试验证任务和界面；真实 RDP 兼容性由使用者人工验收，不阻塞开发交付。
- 其他 RDP 客户端、游戏、自定义控件及受保护输入区域需要各自的验证证据。

兼容性边界：

- 目标程序可以拒绝模拟输入；普通权限工具向高权限程序发送输入可能失败。
- Enter、Tab、输入法状态及目标控件逻辑会影响最终内容。
- “已完成”表示发送结束，使用者仍需检查目标内容。
- 本地工具与 RDP 客户端受本地进程权限约束。远程目标程序的权限不直接决定本地工具的权限。
- 设置、文本和更新偏好统一保存在 `%USERPROFILE%\.key-relay\`。新目录缺少文件时采用默认设置与空数据，原 Windows 应用配置目录文件保留原处。
- 草稿和历史以明文保存，可分别关闭保存并手动清除；目标记录仅驻留内存，具体规则见 INPUT-REQ-007。
