# Project 术语表

## 业务术语

| 术语 | 定义 | 所属 Domain |
| --- | --- | --- |
| 待输入文本 | 使用者在工具中准备、希望发送到目标程序的文本 | text-input |
| 已保存草稿 | 草稿保存开启时保存在本机的最新编辑内容，包含未发送修改，用于启动恢复 | text-input |
| 历史输入记录 | 实际进入发送阶段时保存的完整任务原文、时间及编号，最多保留最近 100 条 | text-input |
| 目标输入位置 | 目标程序中当前能够接收键盘输入的控件及其光标位置 | text-input |
| 输入任务 | 一次启动产生的文本发送过程，包含开始前的等待和发送阶段 | text-input |
| 记录目标 | 最近一次外部物理点击的屏幕坐标、窗口及显示几何信息，仅驻留内存 | text-input |
| 目标激活 | 快捷键或按钮启动后等待操作释放、激活窗口并回点的准备阶段 | text-input |
| 中止 | 结束本次任务，取消尚未发送的内容，保留已发送的内容 | text-input |
| 已完成 | 工具已发送全部文本的任务结果，目标程序的实际接收结果需要另行检查 | text-input |

## 技术术语

| 术语 | 定义 | 相关模块 |
| --- | --- | --- |
| 用户数据目录 | 集中保存设置、草稿、历史及更新偏好的本机目录，位置与默认规则见 INPUT-REQ-007 | text-input |
| 单实例 | 同一 Windows 会话仅保留一个应用实例，重复启动唤起已有窗口 | text-input |
| 键盘焦点 | 决定键盘事件接收位置的系统或程序状态；鼠标停留位置与其含义不同 | text-input |
| 前台窗口 | Windows 当前与使用者交互的前台顶层窗口；同一窗口可以包含多个输入控件 | text-input |
| 全局快捷键 | 工具处于后台时仍可触发的组合键 | text-input |
| 模拟键盘输入 | 通过系统提供的输入机制发送键盘或字符事件 | text-input |
| 实际键盘按键 | 使用者操作键盘产生的按键事件，与工具自身生成的事件区分 | text-input |
