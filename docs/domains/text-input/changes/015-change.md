# 使用 Esc 中止键盘输入并限定启动检查

关联规范：INPUT-REQ-002、INPUT-REQ-003、INPUT-REQ-004、INPUT-REQ-006、[领域概览](../overview.md)、[领域设计](../design.md#系统输入与监听)

## 变更原因

键盘中止操作使用 Esc，启动检查限定为影响输入的按键，避免无关虚拟键的持续按下状态阻止任务启动。

## 变更前

- 等待快捷键释放期间，新按下的其他键盘按键取消准备。
- 输入期间，任意外部键盘按下事件中止任务。
- 快捷键释放、倒计时结束及首字符发送前，检查全部虚拟键状态及全部键盘按下缓存。
- 输入进度提示为“按键或点击停止”。

## 变更后

- Esc 在等待快捷键释放、倒计时和输入阶段取消或中止任务。仅释放 Esc 保持当前任务状态。
- 普通字符、方向键、修饰键和无关功能键保持任务执行，其原有输入效果由当前目标程序处理。
- 鼠标按下中止等待释放和输入任务；倒计时期间允许点击选择目标，鼠标移动与滚轮继续输入。
- 保留倒计时取消按钮、重复开始操作取消任务、工具前台检查及同一次快捷键操作中止后保持结束状态的规则。
- 启动检查包含 Ctrl、Alt、Shift、Win 和鼠标左键、右键、中键、侧键。快捷键启动还需等待本次实际触发的 F8、F9 或 F10 释放。事件携带该键，任务期间保持固定。
- 按钮倒计时结束时，修饰键或鼠标按钮仍被按住则取消任务。无关功能键和普通字符的系统状态及缓存保持任务可启动。
- 键盘操作周期由修饰键及当前选定的开始功能键维护，无关按键的持续状态保持新的独立快捷键操作可识别。更换快捷键后，旧功能键的释放事件继续清理已缓存状态。
- 保留钩子线程的原子中止标记与发送前检查，Esc 或鼠标中止事件到达后取消尚未提交的内容。
- 工具自身发送的事件保持原有识别规则。外部普通键盘注入事件继续任务，外部 Esc 注入事件执行 Esc 中止规则。
- 输入进度提示为“按 Esc 或点击鼠标停止”，桌面应用与 HTML 原型采用相同规则。

### 数据示例

| 输入与操作 | 中间状态 | 最终结果 |
| --- | --- | --- |
| 文本 `abcdef`，按钮倒计时结束，系统仅报告 F22 按下 | 进入输入中，按顺序提交字符 | 完成，已发送 6 / 6 |
| 文本 `abcdef`，已提交 `ab` 后按普通字符 `x` | 保持输入中，目标程序处理 `x` | 继续提交 `cdef`，目标内容可能混合人工与自动输入 |
| 文本 `abcdef`，已提交 `ab` 后按 Esc | 已中止，取消未提交内容 | 已发送 2 / 6，目标程序保留 Esc 原有效果 |
| 文本 `abcdef`，按 Ctrl + Alt + F8，F22 状态持续按下 | 等待 Ctrl、Alt 和 F8 释放 | 启动组合全部释放后发送，F22 保持任务可启动 |
| 文本 `abcdef`，按钮倒计时结束时 Ctrl 仍被按住 | 已取消 | 已发送 0 / 6 |
