# 历史列表隐藏滚动条并保留滚动

关联规范：INPUT-REQ-006、[领域设计](../design.md)、[Windows 人工验收](../../../../tests/manual/windows.md)

## 变更原因

历史列表需要隐藏滚动条并保留原生滚动能力，使不同记录数量下的内容右边缘保持一致。

## 变更前

历史列表根据内容高度显示滚动条，出现滚动条时按其实际宽度分配记录区域。记录较少时，记录外框与清空历史按钮右边缘一致。

## 变更后

- 历史列表保留内部滚动，滚动条隐藏且占用宽度为零。
- 鼠标滚轮、触控板及列表获得焦点后的方向键、PageUp、PageDown、Home、End 使用浏览器原生滚动。
- 空列表、单条记录及 100 条记录均使用全部可用宽度。记录外框与清空历史按钮右边缘一致，工具栏位置与窗口高度保持一致。
- 600px／320px 宽度及 100%／150% 页面缩放下，列表保持横向完整，超出可见高度的记录可通过滚动查看。
- 历史全文、设置与关于区域继续采用各自的滚动样式。搜索、清空确认和历史操作遵循 INPUT-REQ-006。
