# 关于页紧凑布局与可用空间

关联规范：INPUT-REQ-006、[界面设计](../design.md#界面视觉基准)

## 变更原因

关于页采用紧凑更新区，并利用隐藏输入操作区的空间完整展示基础信息。

## 变更前

- 更新标题与检查按钮、自动检查选项、状态提示分别占据三行。
- 关于页与许可证内容限制在共享面板内滚动，底部隐藏的输入操作区保留独立空白。
- 关于页区块间距为 14px，用途说明使用固定换行。

## 变更后

- 常规宽度下，更新区第一行显示标题与检查按钮，第二行左侧显示状态、右侧显示自动检查选项。窄窗口或较长状态允许换行，保留完整文字与控件。
- 更新说明、进度、错误提示及下载和安装操作按现有状态显示。自动检查、签名下载和安装确认规则保持有效。
- 输入操作区与三个面板使用共享网格。关于页及许可证跨越内容区和输入操作区；隐藏的输入控件退出键盘焦点顺序。
- 切换输入、设置、关于及许可证视图保持整体高度一致。编辑框调整、设置错误和文字换行仍参与共享高度计算，关于内容超出可用高度时内部滚动。
- 关于页区块间距为 10px，用途说明按可用宽度自然换行。更新区及支持区分隔线下内边距为 8px，邮箱上外边距为 8px。
- 关于内容可视区域距离窗口内底边 5px，内部内边距为 3px。版权及许可证在空间充足时位于内容底部。
- 原型与桌面端使用相同布局规则。

示例：600px 宽度、编辑框基础高度、安装版处于空闲或已是最新版本状态时，关于页完整展示应用身份、用途说明、更新区、支持信息及版权。切换许可证时窗口高度保持一致，全文在内容区域内滚动。320px 窗口和 150% 缩放下，文字与操作可换行，页面保持无横向溢出。
