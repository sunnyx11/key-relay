# 行尾空白清理与紧凑操作区

关联规范：INPUT-REQ-001、INPUT-REQ-003、INPUT-REQ-006、[领域设计](../design.md#界面视觉基准)、[项目原则](../../../project/principles.md#测试要求)

## 变更原因

文本准备提供可撤销的行尾空白清理，输入页采用单层底部操作区，三个页面共用已确认的按钮尺寸、配色和文字位置。

## 变更前

- 文本准备提供编辑和清空操作。
- 编辑框下方显示字符数和空格、换行说明，底部操作区显示状态、开始和清空按钮。
- 开始按钮使用 172px 预留区域，倒计时按钮显示“取消输入（剩余 N 秒）”。
- 普通按钮背景为 #FAFAFA、文字为 #505050、边框为 #BDBDBD，13px 字号继承 1.5 行高。主按钮背景与边框使用相同蓝色。
- 关于页 MIT 许可证采用文字按钮，更新操作默认靠左，安装确认按钮间距为 6px。

## 变更后

### 文本准备

- “清理”仅在手动触发时删除每行末尾的普通空格 U+0020 和制表符 U+0009，包含无换行的末行。保留缩进、行内空格、换行和空行；其他 Unicode 空白字符按原内容保留。
- 编辑框沿用浏览器换行规范化，清理保持换行数量和位置。字符统计按 Unicode 标量计算，CRLF 计为一个换行。
- 清理从末尾向前逐段选择行尾空白，执行 Chromium 原生删除命令。Ctrl+Z 逐行撤销，Ctrl+Y 逐行重做；清空保留整体撤销和重做。
- 清理、撤销、重做和后续编辑通过现有编辑事件同步字符数与原生草稿。按钮启动提交最新草稿，快捷键使用已同步草稿。
- 没有行尾空白时显示“当前文本没有行尾空格。”，保留编辑历史。成功提示“已去除行尾空格，可按 Ctrl+Z 逐行撤销。”。
- 删除失败时停止剩余操作，保留已完成的编辑，同步实际内容并提示“去除行尾空格未完成，请重试”。
- 空文本禁用清理和清空，开始按钮保留空文本校验。初始化、操作提交、等待释放、倒计时、输入、安装准备和中止鼠标释放保护期间，清理和清空禁用。
- 输入中点击禁用的清理或清空按钮时，该次点击仅中止任务并保留文本；释放后独立操作才执行编辑。
- Enter、Tab 的目标程序语义在使用说明中说明，输入页采用字符统计及状态反馈。

转义字符串示例：

| 输入 | 操作或中间状态 | 输出 |
| --- | --- | --- |
| `"\t第一行  \t\n  第二行 \t\n\n末行  "` | 清理 | `"\t第一行\n  第二行\n\n末行"` |
| `"a  \nb\t"` | 清理 | `"a\nb"` |
| `"a\nb"` | 撤销上述清理一次 | `"a  \nb"` |
| `"a  \nb"` | 再撤销一次 | `"a  \nb\t"` |
| `"a  \nb\t"` | 重做两次 | `"a\nb"` |
| `"abc"` | 清理 | `"abc"`，提示没有行尾空格 |
| `"   "` | 清理 | `""`，字符数为零 |
| `" \t\n\t\n"` | 清理 | `"\n\n"` |
| `"a\u00a0  "` | 清理 | `"a\u00a0"` |

### 布局与状态

- 输入页内容区域仅包含多行编辑框，底部左侧显示状态，右侧依次为字符数、清理、清空、开始输入。按钮组的可访问名称为“输入操作”。
- 字符数与按钮组容器间距为 8px，字符数保留 2px 右外边距；相邻按钮间距统一为 4px。
- 清理和清空宽 44px、高 26px；开始按钮固定宽 72px、高 26px。其他操作按钮采用 26px 最小高度及随文案确定的宽度。
- 按钮字体为 13px、行高为 20px，上下内边距 2px、左右 8px，边框为 1px，圆角为 0。
- 倒计时按钮固定显示“取消输入”，状态显示“等待输入，剩余 N 秒，请选择输入位置。”。秒数使用 Rust 快照的向上取整结果。输入中按钮显示“输入中…”，其他任务状态文案与错误显示优先级沿用现有规则。
- 状态自然换行，保持两行预留高度与垂直居中。内容盒宽度不超过 560px 时状态在上、操作区在下并靠右；操作区允许必要换行。
- 编辑框支持纵向调整，三个页签及许可证保持相同窗口高度，关于页长内容在面板内滚动。

### 公共按钮

- 次级按钮默认背景 #E5E5E5、文字 #252525、边框 #AAAAAA；悬停背景 #F1F1F1、边框 #929292；按下背景 #D7D7D7。
- 主按钮使用白字，默认背景 #326798、边框 #244E75；悬停背景 #2B5B88、边框 #1E4264；按下背景 #244E75、边框 #193752。
- 禁用按钮采用次级按钮背景与边框，文字 #858585。焦点轮廓沿用现有规则。
- 清空悬停背景 #F9EAE8，文字与边框 #A13D32。清理和清空在悬停或键盘焦点时显示用途提示，可访问名称固定为“清理”“清空”，详细描述包含操作范围及撤销方式。
- 设置、关于、许可证及更新操作共用按钮样式。MIT 许可证入口为次级按钮；下载、安装与安装确认操作靠右，确认区域占满可用宽度，确认按钮间距为 4px。
- 下拉框、只读编辑框和标题栏具有各自的颜色定义，保持现有显示。项目支持链接保持链接样式。
- Rust 命令、任务状态、发送规则和配置格式使用现有契约。

本 Change 定义按钮、倒计时展示和操作区的目标规则，[009](009-change.md) 中相应视觉规则由本 Change 的定义取代；其他 Change 的生命周期分别管理。
