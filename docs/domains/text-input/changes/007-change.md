# 关于页与支持入口

关联规范：INPUT-REQ-006、[领域设计](../design.md)、[项目架构](../../../project/architecture.md)、[项目上下文](../../../project/context.md)

## 变更原因

应用需要集中展示身份、版本、支持入口、联系邮箱和离线许可证。

## 变更前

应用提供输入和设置两个页签，版本、版权及支持信息通过仓库文档查看。

## 变更后

- 页签顺序为输入、设置、关于，默认显示输入页。三个页签在相同编辑内容、设置和窗口宽度下保持相同窗口高度。
- 关于页展示 48px K 图标、Key Relay 名称、应用元数据中的版本号、Windows 64 位标识和用途说明。
- 项目主页为 `https://github.com/sunnyx11/key-relay`，使用说明为 `https://github.com/sunnyx11/key-relay#readme`，问题反馈为 `https://github.com/sunnyx11/key-relay/issues`。
- 联系邮箱为 `hkhl888@foxmail.com`。项目链接由系统默认浏览器打开，邮箱通过 `mailto:hkhl888@foxmail.com` 调用默认邮件应用。调用失败时在关于页显示错误并允许重试。
- 版权显示 `© 2026 sunnyx11`。MIT 许可证全文随应用分发，在关于面板内离线查看，提供返回关于的操作。版本读取失败时显示错误并支持重试。
- 关于页使用 Microsoft YaHei UI，名称为 18px 常规字重，说明和链接为 13px，版本和版权为 12px。内容左对齐，使用细分隔线及现有蓝色链接。
- 窄窗口允许换行，溢出内容在面板内部滚动。查看许可证及返回操作保持窗口高度，键盘焦点随本页操作转移。
- 页签支持左右方向键、Home 和 End，跳过禁用项。隐藏面板退出键盘焦点顺序。
- 等待快捷键释放、倒计时和输入期间禁用关于入口。关于页收到活动任务状态时切回输入页，保持目标程序键盘焦点。该次中止点击保持关于入口禁用保护，后续独立操作可进入。
- 文本编辑、任务输入规则、设置保存、窗口置顶和关闭行为保持现有约定。
