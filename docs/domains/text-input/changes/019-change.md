# 记录外部目标并统一回点启动

关联规范：INPUT-REQ-002、INPUT-REQ-003、INPUT-REQ-004、INPUT-REQ-005、INPUT-REQ-006、INPUT-REQ-007、[领域概览](../overview.md)、[领域设计](../design.md)、[项目上下文](../../../project/context.md)、[项目架构](../../../project/architecture.md)、[项目原则](../../../project/principles.md)、[项目术语](../../../project/glossary.md)、[使用说明](../../../../README.md)、[Windows 验收](../../../../tests/manual/windows.md)、[RDP 验收](../../../../tests/manual/rdp.md)

## 变更原因

记录外部点击坐标及目标窗口，让按钮与快捷键共用目标回点流程，并以简短状态和详情浮层展示记录信息。

## 变更前

- 按钮启动默认等待 5 秒，可设置 1～60 秒。倒计时期间点击目标，结束时向当前键盘焦点输入。
- 快捷键在工具处于后台时启动，通过独立的等待释放状态等待组合键释放，再向当前焦点发送。工具处于前台时阻止快捷键启动。
- 工具维护文本草稿及设置，外部点击位置和目标窗口未记录，界面没有目标摘要及详情。

## 变更后

### 目标记录与统一启动

- 空闲时记录外部物理鼠标左键点击的屏幕坐标及顶层窗口。工具内部点击、桌面、任务栏和模拟鼠标事件保留已有记录。目标信息仅驻留内存，表示点击点，输入控件及光标由目标程序处理。
- 按钮与快捷键均要求有效目标，共用文本与设置校验、目标激活状态、窗口与点位校验、回点及首字符发送检查。工具处于前台或后台均可启动。缺少目标时禁用开始按钮，快捷键提示选择输入位置。
- 启动时固定文本、设置和目标。准备阶段最多等待 2 秒释放修饰键及鼠标按钮；快捷键启动还等待本次触发的功能键。释放后激活窗口，确认记录点属于目标，再模拟带自身标记的左键点击。等待目标处理点击后，完成首字符发送前检查并开始输入。
- 目标激活阶段显示“取消输入”。取消按钮、Esc、实际鼠标按下及再次按开始快捷键均可结束准备。取消或等待超时后，同一次快捷键操作保持中止，新的独立操作可重新启动。工具自身模拟鼠标事件保持任务及记录。
- 使用整个虚拟桌面的物理坐标，支持左侧、上方显示器的负坐标。绝对鼠标事件按虚拟桌面范围映射，记录及校验采用每显示器 DPI 感知环境，支持不同缩放比例。
- 启动前校验窗口身份、位置、尺寸、DPI、记录点所在显示器及虚拟桌面范围。窗口失效、最小化、窗口或显示配置变化、记录点被遮挡及激活失败时清除记录，结束准备，提示重新选择，本次发送字符数为零。页面滚动、远程布局或控件变化需要重新点击选择。

### 状态摘要与目标详情

- 有效记录显示单行“已记录输入位置”。尚未记录时显示“请先点击外部输入位置”。目标失效或几何信息变化时显示“目标已失效，请重新选择输入位置”。
- 鼠标悬停或键盘聚焦状态文字时，详情浮层展示完整窗口标题与物理坐标。浮层允许换行，Esc 收起，离开后再次悬停或聚焦可打开。
- 浮层左下角与输入框左下角重合。调整窗口宽度、编辑框高度或页面缩放时保持该位置关系，状态文字至浮层之间具有连续的悬停区域。
- 状态区保留两行预留高度、字体和按钮布局。显示详情时主窗口高度及状态文字位置保持一致，错误与操作提示按需要完整展示。

### 设置与现有输入规则

- 设置包含字符间隔与快捷键。删除等待时间设置、倒计时状态及独立的快捷键等待释放状态，已有设置中的有效字符间隔和快捷键继续保留。
- 文本转换、顺序发送、输入期间当前焦点规则及中止释放保护保持原要求。

### 数据示例

待输入文本为 `abc`，字符间隔为 50 毫秒，目标窗口为“远程桌面连接”。

| 操作或条件 | 结果 |
| --- | --- |
| 点击副屏中的外部输入位置 `(-900, 240)` | 记录窗口与物理坐标，摘要显示“已记录输入位置” |
| 悬停或聚焦状态文字 | 在输入框左下角显示完整窗口标题与 `(-900, 240)` |
| 返回 Key Relay 编辑文本、清理、清空或调整设置 | 保留记录目标 |
| 文本为 `abc` 时点击开始或按 `Ctrl+Alt+F8`，并释放启动操作 | 激活原目标窗口，回点 `(-900, 240)`，目标处理点击后按 50 毫秒间隔接收 `a`、`b`、`c` |
| 启动按键持续按下超过 2 秒 | 取消准备，发送零字符，同一次快捷键操作保持中止 |
| 窗口移动或副屏断开 | 清除失效记录，要求重新选择，两种入口均发送零字符 |
