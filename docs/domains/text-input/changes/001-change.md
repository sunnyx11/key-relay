# 精简桌面标题栏

关联规范：[领域设计](../design.md)

## 变更原因

桌面标题栏保留应用名称和窗口操作，减少辅助装饰。

## 变更前

标题栏展示应用图标、Key Relay 名称、“文本自动输入”辅助描述和窗口操作按钮。窄窗口隐藏辅助描述。

## 变更后

标题栏展示 Key Relay 名称和最小化、最大化／还原、关闭按钮。名称所在区域支持窗口拖动，名称左侧使用标题栏原有内边距。所有宽度采用相同的标题内容。

普通窗口和最大化还原后的窗口高度由内容决定，底部操作区之后紧接窗口边界。
