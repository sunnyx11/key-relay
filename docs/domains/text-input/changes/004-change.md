# 标题与普通按钮的文字层级

关联规范：[领域设计](../design.md)

## 变更原因

应用名称与普通按钮文字在浅色界面中较突出，需要通过字号与颜色表达更柔和的视觉层级。

## 变更前

应用名称使用 13px、400 字重、20px 行高，文字色为 #252525。普通按钮使用 13px、#252525 文字，边框为 #B4B4B4，带有微弱下阴影。

## 变更后

- 应用名称使用 Microsoft YaHei UI、12px、400 字重、20px 行高，文字色为 #5C5C5C。
- “开始输入”“清空”“恢复默认”统一采用 13px、#505050 文字，边框为 #BDBDBD，使用平面样式。
- 普通按钮悬停时文字为 #252525，背景和边框沿用既有悬停反馈。
- 普通按钮禁用文字仍为 #858585，与可操作按钮保持区分。
- 正文、页签、状态文字、窗口图标和按钮点击区域沿用当前视觉规则。
