# 统一主窗口边框

关联规范：INPUT-REQ-006、INPUT-REQ-007、[领域设计](../design.md)

## 变更原因

主窗口四边需要显示一致的边框，同时保留窗口缩放和位置记忆。

## 变更前

- 无装饰窗口启用原生阴影，界面在客户区四边绘制细边框。
- 保存和恢复窗口状态时，按系统缩放比例计算原生边框尺寸。

## 变更后

- 无装饰窗口关闭原生阴影，界面在客户区四边绘制细边框。
- 窗口支持边缘缩放、标题栏拖动、最大化和还原。
- 状态文件继续保存物理屏幕位置和逻辑客户区尺寸。恢复已有记录、校验工作区和保存普通还原矩形时使用无阴影窗口的几何尺寸。
- 普通、最大化和最小化退出后的窗口位置与客户区尺寸遵循 INPUT-REQ-007。
