# 清空历史按钮靠右排列

关联规范：INPUT-REQ-006、[领域设计](../design.md)、[Windows 人工验收](../../../../tests/manual/windows.md)

## 变更原因

清空历史按钮需要靠历史页内容区右侧排列，充分使用工具栏的可用宽度。

## 变更前

历史工具栏和列表保留相同的滚动条占位。工具栏根据记录边框及内边距增加右侧留白，使清空历史按钮与记录删除按钮右边缘一致。

## 变更后

- 历史工具栏左右内边距均为 2px，清空历史按钮靠工具栏内容区右边缘排列。
- 搜索框填充按钮左侧的剩余宽度，搜索框与按钮之间保持 6px 间距。
- 工具栏使用全部可用宽度，列表滚动条在列表内部稳定占位。
- 600px／320px 宽度及 100%／150% 页面缩放下，工具栏允许换行，清空历史按钮保持靠右，控件完整显示。
- 清空确认、搜索、记录操作及公共按钮外观遵循 INPUT-REQ-006。
