# 通知区域与窗口隐藏

关联规范：[领域概览](../overview.md)、[领域设计](../design.md)、[项目架构](../../../project/architecture.md)、INPUT-REQ-007

## 变更原因

通过通知区域管理窗口显示、位置重置和应用退出。

## 变更前

窗口关闭请求启动退出流程，完成保存和资源释放后结束进程。应用没有通知区域图标及菜单，也没有手动重置窗口位置的入口。

## 变更后

- 程序运行期间显示通知区域图标。图标主体大小与相邻应用图标接近，并保留原有颜色与图形。左键单击打开窗口。
- 图标右键菜单依次提供“打开窗口”“重置位置”“退出应用”。
- 标题栏关闭按钮、Alt+F4 和任务栏关闭窗口请求隐藏主窗口，进程继续运行。最小化按钮维持原有行为。
- 打开窗口时显示并还原主窗口，保留编辑内容和置顶状态。
- 重置位置时保留窗口尺寸，将窗口移至主屏幕工作区中央并打开。
- 退出应用沿用既有保存和资源释放流程。保存失败时保持运行，显示窗口并提示错误。
- 安装进行中的关闭与退出遵循安装互斥规则。
