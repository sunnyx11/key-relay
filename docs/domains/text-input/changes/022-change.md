# 窗口视口布局与紧凑启动

关联规范：INPUT-REQ-006、[领域设计](../design.md)、[Project 原则](../../../project/principles.md)、[Windows 验收](../../../../tests/manual/windows.md)、[原型说明](../../../../prototypes/README.md)

## 变更原因

页面需要完整使用窗口可视区域，并以最小高度启动，使紧凑窗口中的状态、操作及长内容保持可用。

## 变更前

- 窗口高度由共享网格中的输入框、状态和操作区决定，普通窗口及最大化还原后按内容调整原生高度。
- 编辑框基础高度和最小高度为 226px，支持纵向拖动；编辑框高度影响全部页签的共享高度。
- 最大化只扩大原生窗口，页面保持按内容计算的高度；原型最大化演示仅扩大宽度。
- 历史、设置、关于及许可证在由输入页确定的共享区域内滚动。
- 工具窗口内容盒宽度不超过 560px 时，底部状态与操作按钮采用上下排列。
- 原生窗口默认尺寸为 600×450px，最小尺寸为 320×364px。默认高度足以完整显示关于页基础信息。

## 变更后

- 所有页签的外框填满当前窗口可视区域。普通窗口调整大小、最大化和还原时，内容随可用宽高重新布局。
- 标题栏、页签栏及当前页面的底部操作区保留自身高度，中间区域填充剩余高度。底部操作区紧邻窗口下边缘。
- 输入框填满中间区域，原生纵向拖动柄关闭。文本超出可见范围时在编辑框内部滚动。
- 历史列表、历史全文、设置、关于和许可证填充各自可用区域，长内容在面板内部滚动。切换页签、显示错误及更新状态保持窗口尺寸。
- 原生窗口尺寸由窗口操作决定。页面在隐藏启动后执行首次显示，内容变化通过重新分配中间区域高度处理，原生窗口保持当前尺寸。
- 工具窗口内容盒宽度大于 420px 时，底部状态与操作按钮横向排列；不超过 420px 时采用上下排列。状态区高度固定为两行，长内容在状态区内部滚动。
- 首次启动及关闭后重新打开时，原生窗口以 600×340px 居中创建。最小尺寸为 320×340px，启动高度与最小高度相同。创建时保持隐藏，前端准备完成后显示窗口。
- 已有实例重复启动时，还原并显示原窗口，保留当前手动调整的尺寸。
- 默认高度下，关于页通过内部滚动查看完整信息。在 600×450px 窗口、安装版处于空闲或已是最新版本时，关于页基础信息完整显示。
- 顶部提示或底部状态内容变化时，在可视区域内重新分配中间高度。窄窗口及 150% 缩放下保留内部滚动和完整操作入口。
- 原型采用相同的高度分配规则及底部断点，覆盖 340px 高的页面内窗口，最大化和还原同时演示宽高变化。

| 输入与操作 | 结果 |
| --- | --- |
| 首次启动或关闭后重新打开 | 新建 600×340px 窗口，居中显示 |
| 将窗口调整为 600×450px 后重复启动 | 还原并显示已有窗口，保留 600×450px 尺寸 |
| 在默认窗口切换输入、历史、设置、关于及许可证视图 | 页面填满 600×340px 可视区域，长内容内部滚动 |
| 同宽窗口由 450px 增高到 881px | 顶部和底部保留自身高度，中间区域增加 431px |
| 最大化后查看历史全文，再还原 | 全文区域随可视高度变化，窗口还原到先前尺寸 |
| 文本或许可证长于面板 | 当前内容区域内部滚动，顶部与底部保持可见 |
| 输入框右下角操作 | 编辑框高度由可视区域分配，原生纵向拖动柄关闭 |
| 510px 宽窗口查看状态与输入操作 | 状态与字符数、清理、清空、开始按钮保持同行 |
| 内容盒宽度从 421px 缩小为 420px | 底部从横向排列变为状态在上、操作在下 |
| 窗口缩小到 320×340px | 停留在最小尺寸，输入框保留可用高度，各页签内容内部滚动 |
| 拖动窗口边缘继续缩短高度 | 窗口保持 340px 的最小高度 |
