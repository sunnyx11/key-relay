# 简化关于页更新信息

关联规范：INPUT-REQ-008、[界面设计](../design.md#关于页)

## 变更原因

关于页更新区仅展示判断和执行更新所需的信息，具体发布说明由 GitHub Release 提供。

## 变更前

- 检查到更新后，关于页以纯文本展示发布说明，包含 Markdown 标题与列表符号。
- 较长发布说明在 100px 高度内滚动。

## 变更后

- 关于页展示更新状态、目标版本、自动检查选项，以及当前阶段的下载进度、错误提示和操作。
- 发布说明正文从关于页与原型中移除，GitHub Release 继续提供完整说明。更新清单及状态快照中的说明字段保持现有契约。
- 发现新版本及安装就绪时保留关于页签标记。检查、下载、签名验证及安装确认规则保持有效。

示例：检查返回版本 `0.3.0`，说明为 `### Fixed\n\n- 改善输入体验。`。安装版关于页显示“发现新版本 0.3.0”和“下载更新”，说明正文仅在 GitHub Release 中提供。下载后显示安装就绪状态，点击“安装并重启”仍需确认文本清除提示。
