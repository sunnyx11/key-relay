# 分离式 K 应用图标

关联规范：[领域设计](../design.md)

## 变更原因

应用采用已选定的 B 方案，以简洁的字母 K 作为 Windows 应用标识。

## 变更前

应用使用浅灰底、蓝色键盘轮廓和多排键位图标。

## 变更后

- 应用采用 B「分离结构」：竖笔与两条相连斜笔之间保留间隙，使用圆角线端。
- 圆角底色为 #F1F4F7，字形为 #326798，外部区域透明。
- SVG 保存字形源文件，ICO 提供 Windows 程序、NSIS 安装程序和卸载程序所需的多尺寸资源。构建脚本跟踪 ICO 文件变化。
- 自定义标题栏继续展示应用名称和窗口操作按钮。
