# 用户主目录存储、单实例唤起与历史全文查看

关联规范：INPUT-REQ-006、INPUT-REQ-007、INPUT-REQ-008、[领域需求](../requirements.md)、[领域概览](../overview.md)、[领域设计](../design.md)、[项目上下文](../../../project/context.md)、[项目架构](../../../project/architecture.md)、[项目原则](../../../project/principles.md)、[术语表](../../../project/glossary.md)、[发布验收](../../../release.md)、[使用说明](../../../../README.md)、[Windows 验收](../../../../tests/manual/windows.md)

## 变更原因

统一用户数据位置，通过重复启动唤起已有窗口，并将历史查看与恢复操作分开。

## 变更前

- 设置、草稿、历史及更新偏好保存在 Windows 应用配置目录。
- 多个应用进程可以同时启动，文本文件独占锁使后续实例显示读取错误。
- 点击历史正文恢复编辑内容，记录右侧仅有删除按钮。
- 历史操作按钮与清空历史按钮的右边缘各自取决于列表和工具栏布局。

## 变更后

- 正常运行使用 `%USERPROFILE%\.key-relay\`，在该目录保存 `settings.json`、`text.json`、`text.json.lock` 和 `updates.json`。独立 EXE 和安装版使用同一目录。
- 新目录缺少文件时采用默认设置、空草稿和空历史。旧应用配置目录中的文件保留原处，应用只读取新目录。既有新目录数据继续使用。
- `KEY_RELAY_TEST_CONFIG_DIR` 继续支持隔离测试，设置、文本和更新偏好统一使用指定目录。
- 单实例检查位于配置读取、文本存储线程、快捷键和系统钩子初始化之前。重复启动通知已有进程并退出；已有窗口最小化时还原，随后显示并请求前台焦点。保留已有窗口内容、当前页签和置顶状态。
- 历史正文保留两行预览，点击后在历史页内查看只读全文，保留换行和缩进，全文区域内部滚动。返回列表时保留搜索条件和滚动位置，焦点返回对应正文按钮。
- 每条历史包含独立的公共“恢复”和“删除”按钮。恢复继续整体替换编辑内容，支持 Ctrl+Z/Ctrl+Y，并切回输入页聚焦末尾；查看全文只改变历史页显示状态。
- 删除按钮右边缘与清空历史按钮右边缘一致。覆盖 600px、320px 与 100%、150% 页面缩放，记录和全文内容保持内部滚动，页签及窗口高度保持一致。
- 底部说明正文用于查看全文，“恢复”按钮用于填入编辑框。活动任务、安装、读取和命令提交期间继续遵守操作保护。
- 本 Change 取代 Change 020 中旧配置目录、第二实例占用错误及点击正文恢复的目标规则；草稿、历史保存和退出协调规则继续有效。

| 输入与操作 | 中间状态 | 最终结果 |
| --- | --- | --- |
| 旧目录有草稿 `old`，新目录没有文本文件 | 从新目录加载默认文本状态 | 编辑框与历史为空，旧文件原样保留 |
| 新目录保存草稿 `new` 后再次启动 | 从新目录读取文本状态 | 恢复 `new`，旧目录保持原样 |
| 已有窗口最小化且编辑内容为 `beta`，再次启动应用 | 新进程通知已有进程并退出 | 原窗口还原并获得焦点，编辑内容仍为 `beta` |
| 当前编辑为 `beta`，点击历史 `alpha\n  end` 正文 | 历史页显示完整只读文本 | 编辑仍为 `beta`，没有新增历史 |
| 返回列表后点击该条“恢复” | 原生编辑器整体替换为 `alpha\n  end` | 切回输入页，Ctrl+Z 恢复 `beta` |
