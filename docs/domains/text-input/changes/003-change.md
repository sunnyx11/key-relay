# 标题栏文字与图标比例

关联规范：[领域设计](../design.md)

## 变更原因

标题文字与窗口图标的比例、线条和垂直位置需要统一，适配紧凑标题栏。

## 变更前

应用名称为 14px、400 字重、1.5 行高。图标显示为 12×12px，图钉使用 16×16 坐标，其他图标使用 12×12 坐标。图钉线条和轮廓较小，最小化横线位于图标下部。

## 变更后

- 应用名称采用 Microsoft YaHei UI、13px、400 字重、20px 行高。
- 四个窗口图标共用 16×16px 画布和坐标，使用 1px 线宽及圆角线端、连接处。轮廓宽度约 8～9px，图钉针尖略长以保留辨识度。
- 最小化横线、最大化方框与关闭交叉线在画布内居中，图钉围绕画布中心表达倾斜与固定状态。
- 普通图标使用中性灰，悬停时采用正文色；置顶选中、禁用及关闭悬停使用对应状态色。
- 标题栏仍为 28px，按钮点击区域为 32×27px。按钮内边距为零，焦点轮廓置于按钮内部。
