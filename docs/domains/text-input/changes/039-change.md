# 按钮启动与实时按键释放检查

关联规范：INPUT-REQ-001、INPUT-REQ-002、INPUT-REQ-003、INPUT-REQ-004、INPUT-REQ-005、INPUT-REQ-006、INPUT-REQ-007、INPUT-REQ-008、[领域概览](../overview.md)、[领域设计](../design.md)、[项目上下文](../../../project/context.md)、[项目架构](../../../project/architecture.md)、[项目原则](../../../project/principles.md)、[术语表](../../../project/glossary.md)、[版本发布](../../../release.md)

## 变更原因

使用按钮启动和系统实时按键状态检查，消除长期按键缓存遗漏释放事件后持续阻止发送的问题。

## 变更前

- 按钮及 Ctrl+Alt+F8/F9/F10 全局快捷键均可启动，活动任务中的快捷键可中止任务。
- 设置包含字符间隔和快捷键，快照包含快捷键注册错误。
- 启动准备同时检查系统实时状态与长期按键缓存。快捷键另记录操作周期及触发功能键。
- 释放事件遗漏后，缓存中的修饰键可跨任务保留。实时状态全部释放时仍可能等待至两秒超时。
- 安装准备、失败恢复和退出分别管理输入监听及快捷键注册。

## 变更后

- “开始输入”按钮为发送启动入口，准备期间为“取消输入”。保留 Esc 中止、鼠标记录目标与中止、注入事件识别和鼠标中止释放保护。
- 启动前实时查询 Ctrl、Alt、Shift、Win 和鼠标按钮，最多等待两秒释放。首字符发送前再次检查。普通字符、方向键及功能键由目标程序处理。
- 键盘监听只处理外部 Esc 按下。按键释放判断使用当前系统状态，任务与钩子均省去长期按键集合、启动功能键和快捷键操作周期。
- 设置仅包含字符间隔 `intervalMs`，默认 50 毫秒，范围为 10～1,000 的整数。旧文件的额外字段遵循现有解析规则，保存只输出当前设置字段。
- 前端设置、草稿和快照采用相同字段契约，界面说明与原型按按钮启动表达。
- 安装准备阻止新任务并释放输入监听；保存或空闲检查失败时保留原监听。已释放监听后安装启动失败时尝试重新建立监听，恢复失败显示错误。设置、草稿、历史及更新数据保留。退出时释放输入监听。

| 输入与操作 | 中间状态 | 输出 |
| --- | --- | --- |
| `settings.json` 为 `{"intervalMs":120,"shortcut":"F10"}` | 读取字符间隔 120 | 保存为 `{"intervalMs":120}` |
| 文本 `abc`，有效目标，点击开始时 Ctrl 仍按住 | 等待当前系统状态；释放后激活并回点 | 依次发送 `a`、`b`、`c` |
| 运行期间发生过修饰键按下，释放事件未被监听收到；启动时系统报告全部释放 | 当前系统状态允许准备 | 正常激活并发送 |
| 点击开始后修饰键持续按住两秒 | 准备超时 | 取消，发送零字符；释放后可重新点击开始 |
| 空闲时按 Ctrl+Alt+F8/F9/F10 | 保持空闲 | 组合键保留系统原有效果 |
| 输入期间按 Esc 或鼠标按钮 | 中止尚未提交内容 | 保留已发送数量及原编辑内容 |
