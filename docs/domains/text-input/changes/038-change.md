# 使用 Node.js 22.22.2 构建

关联规范：[版本发布](../../../release.md)、[项目上下文](../../../project/context.md)

## 变更原因

开发和发布构建使用 Node.js 22.22.2 作为版本基准。

## 变更前

开发环境要求 Node.js 24 或更高版本，发布构建与检查使用 Node.js 24。

## 变更后

开发环境要求 Node.js 22.22.2 及以上的 22.x 版本、24.x 版本或 26.0.0 及以上版本。发布前端与构建任务使用 Node.js 22.22.2。Node 类型定义使用 22 主版本。
