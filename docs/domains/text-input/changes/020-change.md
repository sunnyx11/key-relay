# 启动草稿恢复与历史输入记录

关联规范：INPUT-REQ-001、INPUT-REQ-003、INPUT-REQ-006、INPUT-REQ-007、INPUT-REQ-008、[领域需求](../requirements.md)、[领域概览](../overview.md)、[领域设计](../design.md)、[项目上下文](../../../project/context.md)、[项目架构](../../../project/architecture.md)、[项目原则](../../../project/principles.md)、[术语表](../../../project/glossary.md)、[发布验收](../../../release.md)、[使用说明](../../../../README.md)、[Windows 验收](../../../../tests/manual/windows.md)

## 变更原因

保存最近草稿和历史输入，使重新启动与重复输入能够恢复完整文本。

## 变更前

- 文本仅驻留内存，退出与更新重启后编辑框为空。
- 输入、设置、关于三个页签；设置保存字符间隔和快捷键。
- 编辑框原生撤销记录只在当前会话有效。
- 没有持久化输入历史或恢复入口。

## 变更后

- 启动恢复最新草稿，包含未发送的修改。读取期间只读；读取失败提供重试，避免以空草稿覆盖原文件。保存失败提示并允许重试。
- 编辑、清理、清空与历史恢复更新草稿。清空后下次启动为空，历史列表保留。
- 页签依次为输入、历史、设置、关于。历史列表内部滚动，按最近时间倒序及今天、昨天、日期分组；预览保留缩进和换行并限制两行；显示时间和 Unicode 字符数。
- 搜索匹配完整文本。点击记录整体替换编辑框、切回输入、聚焦且光标位于末尾；Ctrl+Z 撤销整体替换。短暂恢复提示后回到目标提示。
- 后端在任务进入实际发送阶段时记录冻结原文，包括单字符任务及随后中止的任务。准备阶段取消、编辑与恢复均不新增历史。
- 与最近一条内容完全相同则更新时间；最多保存最近 100 条，超出时移除最早记录。
- 单条删除提供短暂撤销；清空历史需二次确认，仅清除历史列表。
- 设置提供默认开启的“保存并恢复上次编辑内容”和“保存历史输入记录”。关闭保存时保留已有数据，并提供清除已保存内容的操作。
- 新增操作按钮采用公共 26px、1px 直角样式。320px 与 600px、100% 与 150% 页面缩放下可操作；历史长度不改变窗口高度。
- targeting、typing、interactionBlocked、安装、未初始化及启动请求期间禁用历史修改，遵循同次鼠标中止点击保护。
- 文本保存在当前用户本机配置目录，日志与错误保持省略文本原文。外部目标记录继续仅驻留内存。
- 安装更新前等待最新草稿与设置保存；保存关闭时提示本次未保存内容在重启后清除。本 Change 取代 Change 010 中更新重启一律清除文本的规则。
- 正常退出先停止活动任务，禁止继续编辑，等待前端编辑队列和最近有效设置、文本写入；保存失败保持应用运行供重试。
- 同一文本存储由一个运行实例独占。第二个实例显示可重试读取错误，关闭占用实例后可读取完整数据。桌面测试使用独立临时配置目录。

| 输入与操作 | 中间状态 | 最终结果 |
| --- | --- | --- |
| 编辑 `a\n  b` 后退出 | 最新草稿保存完整文本 | 重启编辑框为 `a\n  b`，目标为空 |
| `alpha` 开始输入后中止，再次发送同文 | 历史先含一条 alpha，再更新时间 | 一条 alpha，正文完整 |
| 当前 `beta`，点击 alpha 历史 | 原生编辑器整体替换为 alpha | Ctrl+Z 恢复 beta，字符数与草稿同步 |
| 清空编辑器 | 最新草稿为空，历史仍含 alpha | 重启空编辑器，历史可恢复 alpha |
| 关闭两个保存选项后编辑并发送 gamma | 已有草稿及历史保留 | 重启空编辑器，历史未新增 gamma |
