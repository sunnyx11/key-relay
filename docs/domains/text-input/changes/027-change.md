# 历史列表按需分配滚动条空间

关联规范：INPUT-REQ-006、[领域设计](../design.md)、[Windows 人工验收](../../../../tests/manual/windows.md)

## 变更原因

历史列表需要在有滚动条和无滚动条时充分使用可用宽度，使无滚动条时的记录外框与工具栏右侧一致。

## 变更前

历史工具栏使用全部可用宽度，列表通过稳定滚动条占位预留右侧空间。记录较少或列表为空时，列表仍保留滚动条宽度，记录外框与清空历史按钮右边缘之间存在额外空白。

## 变更后

- 历史列表的纵向滚动条按内容高度出现，空间按实际滚动条分配。
- 记录较少时，记录外框与清空历史按钮右边缘一致。空列表使用全部可用宽度。
- 记录超出可见高度时，列表内部滚动，记录使用滚动条左侧的可用宽度。工具栏位置保持一致。
- 600px／320px 宽度及 100%／150% 页面缩放下，空列表、单条记录和 100 条记录均保持横向完整及窗口高度。
- 搜索、清空确认、历史恢复和记录操作遵循 INPUT-REQ-006。
