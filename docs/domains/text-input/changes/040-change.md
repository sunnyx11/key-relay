# 历史记录列表增加复制按钮

关联规范：INPUT-REQ-006、[领域设计](../design.md)、[Windows 人工验收](../../../../tests/manual/windows.md)

## 变更原因

在历史记录右侧操作区第二个位置增加复制图标按钮，使历史原文无需恢复到输入框即可直接复制到系统剪贴板。

## 变更前

- 历史记录右侧依次提供置顶、恢复和删除三个 26×26px 图标按钮（间距 4px），不包含直接复制记录原文的操作入口。
- 历史工具栏中搜索框与“清空历史”按钮间距为 6px，输入操作等公共按钮组相邻间距为 4px。
- 历史页底部说明提示“点击内容查看全文，点击“恢复”填入输入框”。

## 变更后

- 每条历史记录右侧依次提供置顶、复制、恢复和删除四个 26×26px 图标按钮，相邻间距为 3px，沿用公共次级按钮样式与 16×16px、1px 线宽线性 SVG 图标。
- 历史工具栏（搜索框与“清空历史”按钮）及公共操作按钮组（输入页底部“清理”“清空”“开始输入”等）相邻间距统一调整为 3px。
- 复制按钮使用重叠双矩形线性图标，`title` 为“复制记录”，可访问名称为“复制记录：<原文前 80 个字符>”。
- 点击复制按钮将对应记录的完整原文（保留换行、缩进和空行）写入系统剪贴板，同时保留当前历史页、搜索条件、列表滚动位置、编辑框文本、历史记录以及已记录的外部目标位置。
- 复制成功后，该按钮图标临时切换为勾选 SVG 并在历史页底部状态区显示“已复制历史内容”，2 秒后自动恢复默认图标与底部说明；复制失败时在历史页底部状态区以错误色显示“复制失败，请重试”。切换页签、进入查看全文或进入保护状态时清除上述临时提示状态。
- 复制按钮在初始化、活动任务、安装、存储提交及中止鼠标释放保护期间禁用，遵循同次中止点击保护。
- 历史页底部说明调整为“点击内容查看全文，点击“复制”或“恢复”使用内容”。

| 输入与操作 | 中间状态 | 最终结果 |
| --- | --- | --- |
| 原文为 `第一行\n  第二行`，点击右侧第 2 个按钮 | 调用系统剪贴板写入完整 `第一行\n  第二行` | 剪贴板写入完整原文，按钮图标切为勾选且底部显示“已复制历史内容”，2 秒后恢复默认，编辑框与列表位置不变 |
| 剪贴板写入被拒绝或接口不可用 | 捕获异常并停止后续成功反馈 | 底部状态区以错误色显示“复制失败，请重试”，历史记录与编辑框内容保留 |
| 目标激活、输入中或释放保护期间点击或尝试触发复制 | 按钮处于禁用状态 | 保持禁用保护，不触发剪贴板写入 |
