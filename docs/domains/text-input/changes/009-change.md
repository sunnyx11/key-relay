# 直角控件与主操作视觉层级

关联规范：[界面视觉基准](../design.md#界面视觉基准)、INPUT-REQ-006

## 变更原因

界面采用直角控件和蓝色主按钮，通过统一标题栏底色与增加少量底部留白表达紧凑桌面工具的操作层级。

## 变更前

- 操作按钮圆角为 3px，设置控件圆角为 2px，编辑框为直角。
- 开始、清空、恢复默认等操作按钮共用浅灰背景及交互配色，开始按钮通过位置与文案识别。
- 标题栏为白色，普通标题栏按钮悬停背景为 #F1F1F1。
- 底部操作区下内边距为 4px，普通和窄窗口一致。
- 文本编辑框、设置数值框和快捷键下拉框的焦点轮廓宽 2px、向外偏移 2px，焦点轮廓超出控件原有边界。

## 变更后

- 按钮、页签、输入框、下拉框和数值控件外框采用直角。应用图标和窗口图标笔画保持现有造型。
- 开始按钮使用白色文字。默认背景与边框为 #326798，悬停为 #2B5B88，按下为 #244E75。可操作状态的文字对比度至少为 4.5∶1。
- 倒计时期间，同一按钮显示“取消输入（剩余 N 秒）”并使用主按钮配色。等待释放、输入中及其他禁用状态使用现有浅灰背景 #FAFAFA、边框 #BDBDBD 和禁用文字 #858585，停止悬停及按下反馈。
- 清空、恢复默认、返回关于等次级按钮采用现有浅灰配色。操作按钮共用尺寸、字体、直角边框及焦点规则，主按钮单独表达操作层级。
- 标题栏背景为 #F3F3F3，与主界面一致。普通标题栏按钮悬停背景为 #E9E9E9，置顶选中和关闭悬停采用既有状态色。
- 底部操作区下内边距为 8px，普通和窄窗口一致。
- 状态区两行预留高度、开始按钮 172px 预留区域、字体、字号、控件尺寸、页签结构和响应式断点采用现有规则。
- 文本编辑框、设置数值框和快捷键下拉框的焦点轮廓宽 2px，偏移为 -2px，沿原有边界向内绘制。聚焦前后，控件外边界、文本内边距及布局尺寸保持一致。数值框轮廓包围包含单位的整个控件。其他控件采用现有焦点规则。
- 编辑框支持内部滚动和纵向拖拽，普通窗口高度由内容决定，各页签保持等高。文本编辑、任务控制、窗口操作及键盘交互采用现有规则。
- 桌面界面与独立原型采用相同的控件外形、状态配色和间距。
