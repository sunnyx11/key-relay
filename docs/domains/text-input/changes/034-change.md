# 统一历史搜索框焦点及确认区对齐

关联规范：INPUT-REQ-006、[领域设计](../design.md#界面视觉基准)

## 变更原因

历史搜索框与文本编辑框采用一致的焦点轮廓，清空历史确认区的复选框与文字垂直居中对齐。

## 变更前

历史搜索框沿用通用控件的外偏移焦点轮廓，文本编辑框的焦点轮廓沿原有边界向内绘制。清空历史确认区包含“同时删除置顶记录”复选框及其文字。

## 变更后

- 历史搜索框和文本编辑框共用文本控件的边框、背景及焦点样式。焦点轮廓宽 2px，向内偏移 2px，聚焦前后控件外边界和布局尺寸保持一致。
- 搜索框保留单行搜索、过滤及清空历史成功后聚焦规则。文本编辑框保留原生编辑、撤销及重做规则。
- 清空历史确认区的复选框与文字垂直居中，保留原生复选框、标签关联和清空操作规则。
