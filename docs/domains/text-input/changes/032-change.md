# 历史摘要序号使用主题蓝色

关联规范：INPUT-REQ-006、[领域设计](../design.md#界面视觉基准)

## 变更原因

历史摘要序号使用主题蓝色，与正文颜色区分。

## 变更前

历史摘要序号与正文使用相同文字样式，序号后接一个普通空格。序号按当前可见记录顺序从 1 开始，跨置顶组和日期组连续编号。

## 变更后

- 历史摘要序号使用现有主题蓝色 `#326798`，正文使用现有正文颜色。
- 序号使用独立的行内元素，颜色引用公共主题变量 `--accent`。序号与正文共用字体、字号和行高，整体遵循单行显示及超宽省略规则。
- 序号后接一个普通空格。连续编号、过滤排序、原文保存、全文查看及恢复按 INPUT-REQ-006 执行。

原文为 `甲\n第二行` 时，列表摘要为 `1 甲 第二行`，其中 `1` 为主题蓝色，正文为正文颜色。全文查看及恢复内容为 `甲\n第二行`。
