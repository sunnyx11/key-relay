# 发布独立程序附件包含版本号

关联规范：[发布说明](../../../release.md)

## 变更原因

独立程序发布附件的名称包含版本和架构，便于区分不同版本。

## 变更前

发布附件中的独立程序名为 `key-relay.exe`。本地构建产物和安装目录中的程序使用同名文件。

## 变更后

- 独立程序发布附件使用 `key-relay_<版本>_x64.exe`。例如标签 `v0.4.0` 生成 `key-relay_0.4.0_x64.exe`，标签 `v0.4.0-rc.1` 生成 `key-relay_0.4.0-rc.1_x64.exe`。
- 附件从本地构建产物 `src-tauri/target/release/key-relay.exe` 复制，保留原始字节。校验文件及草稿上传使用版本化附件名。
- 安装包、安装目录中的程序、更新清单和已公开的历史 Release 保持现有规则。同标签草稿仅替换同名附件。
