# 历史摘要显示连续序号

关联规范：INPUT-REQ-006、[领域设计](../design.md#历史与文本保存)

## 变更原因

历史列表需要在每条摘要开头显示连续序号，方便确认记录在当前列表中的位置。

## 变更前

历史列表先显示置顶组，再显示按日期分组的普通记录，组内按记录时间和持久化编号倒序。摘要从原文首字开始，仅将换行显示为空白。

## 变更后

- 每条摘要在原文首字的位置显示十进制序号，从 1 开始，按当前可见记录顺序跨置顶组和日期组连续编号。
- 序号与正文之间使用一个普通空格，沿用摘要的字体、字号、颜色、单行显示及省略规则。
- 搜索、置顶、取消置顶、删除及记录更新后，按当前可见列表重新连续编号。空列表保持现有空状态。
- 序号由前端在全文过滤和排序后、日期分组前生成，仅用于摘要显示。持久化编号、原文、搜索匹配、全文查看和恢复内容保持各自现有规则。

输入记录按显示顺序为置顶的 `甲`、今天的 `乙\n第二行`、昨天的 `丙`，列表摘要分别为 `1 甲`、`2 乙 第二行`、`3 丙`。搜索 `第二行` 后，仅显示 `1 乙 第二行`。查看全文或恢复时，内容为 `乙\n第二行`。
