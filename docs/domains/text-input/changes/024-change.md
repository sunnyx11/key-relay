# 主窗口大小和位置记忆

关联规范：INPUT-REQ-006、INPUT-REQ-007、[领域设计](../design.md)、[项目架构](../../../project/architecture.md)

## 变更原因

程序需要恢复上次退出前的普通窗口大小和位置，并在显示器变化导致位置失效时提供可操作的默认位置。

## 变更前

- 首次启动和关闭后重新打开均以 600×340 的默认尺寸在主显示器居中。
- 单实例重复启动保留已有窗口的尺寸和位置。
- 用户目录保存输入设置、文本和更新偏好，窗口几何仅保留在当前进程。

## 变更后

- 正常退出和安装更新前，将普通窗口的还原大小和位置保存到用户主目录 `.key-relay/window-state.json`；测试目录覆盖适用于该文件。
- 位置使用物理屏幕坐标，客户区大小使用逻辑尺寸。跨显示器及缩放恢复依据当前显示器工作区和倍率校验。
- 启动时在首次显示前恢复状态。有效窗口矩形必须完整位于某一显示器的可用工作区，负坐标有效。
- 位置失效时保留可用的上次大小，在主显示器工作区居中。尺寸超过工作区时，在最小 320×340 的约束内缩小；工作区小于最小尺寸时优先保留最小尺寸，并保证标题栏位于工作区顶部。
- 缺少记录、记录损坏或尺寸无效时使用默认 600×340 并居中。读取及保存失败记录诊断信息，窗口状态错误不阻止启动或退出。
- 最大化或最小化退出时保存普通窗口的还原几何，重新打开使用普通窗口。默认置顶规则保持有效。
- 已运行程序的重复启动继续唤起原窗口，保留当前状态。
- 异常终止使用最近一次成功保存的记录。

| 输入和当前显示环境 | 判断 | 启动结果 |
| --- | --- | --- |
| 无记录，主屏工作区 `(0,0,1920,1040)`，100% 缩放 | 使用默认几何 | 客户区 600×340，主屏居中 |
| 记录位置 `(100,120)`、客户区 600×450，主屏工作区足够 | 矩形完整位于工作区 | 恢复原位置和大小 |
| 记录位置 `(-1600,100)`，左侧副屏工作区 `(-1920,0,1920,1040)` | 负坐标属于副屏 | 恢复副屏位置和大小 |
| 原副屏已断开，记录位置与任何工作区均不相交 | 位置失效 | 保留可用大小，主屏居中 |
| 窗口部分超出工作区或位于多屏空隙 | 位置失效 | 保留可用大小，主屏居中 |
| 记录尺寸为零、负数或文件损坏 | 记录无效 | 默认 600×340，主屏居中 |
| 最大化或最小化退出 | 使用普通还原矩形 | 普通窗口恢复上次还原大小和位置 |
