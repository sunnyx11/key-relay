# 紧凑布局与窗口置顶

关联规范：[领域设计](../design.md)、INPUT-REQ-006、INPUT-REQ-007

## 变更原因

缩减窗口外围留白，统一使用 Microsoft YaHei UI，并提供图钉置顶操作。

## 变更前

标题栏高度 36px，按钮为 38×35px，名称字重 600。页签上方间距 10px；底部上内边距 10px，下内边距为 14px，窄窗口为 12px。字体优先使用 Segoe UI。窗口最小高度为 380px，标题栏提供最小化、最大化／还原和关闭。

## 变更后

- 标题栏高度 28px，按钮为 32×27px，名称采用 14px、400 字重。
- 页签上方间距 8px；底部上内边距 6px，下内边距统一 4px。保留状态区两行高度、26px 操作按钮、编辑区与左右间距。
- 全界面字体顺序为 Microsoft YaHei UI、Microsoft YaHei、sans-serif。
- 前端和原生窗口最小高度统一为 360px，窗口实际高度随内容变化。
- 图钉位于最小化左侧，点击开启置顶，再次点击取消。选中时使用蓝色背景和固定状态图标，提示文字分别为“置顶窗口”“取消置顶”。
- 置顶仅改变窗口层级，目标程序可获得键盘焦点；最小化恢复保留置顶状态，退出后重新打开为普通窗口。
- 读取或设置失败时显示可见错误，图钉反映最后确认的窗口状态，允许重试。
- 活动任务期间禁用图钉。实际鼠标按下按既有中止规则处理，同一次中止点击保留置顶状态，下一次独立点击才切换。
