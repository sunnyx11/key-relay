# 输入框最小高度 226px

关联规范：[领域设计](../design.md#界面视觉基准)、[项目原则](../../../project/principles.md#测试要求)

## 变更原因

输入框最小显示高度采用 226px，增加默认可编辑区域，保持页签等高和紧凑的底部操作区。

## 变更前

- 编辑框基础高度和最小高度均为 216px，面板最小高度为 228px。
- 默认 600px 宽度下，原生窗口高度为 354px；前端尺寸计算和原生窗口下限均为 354px。

## 变更后

- 编辑框基础高度和最小高度均为 226px，面板最小高度为 238px，含 12px 上内边距。
- 默认 600px 宽度且设置有效时，编辑框显示高度为 226px，原生窗口高度为 364px；前端尺寸计算和原生窗口下限均为 364px。
- 编辑框支持拖动增高并缩回最小尺寸。窄窗口、设置错误提示和文字换行可以撑高共享面板。
- 输入、设置、关于和许可证在相同状态下保持等高，底部操作区紧邻编辑框。
- 原型、桌面应用和尺寸检查采用相同规则。
