# 主窗口默认置顶

关联规范：INPUT-REQ-007、[领域设计](../design.md)、[Windows 验收](../../../../tests/manual/windows.md)

## 变更原因

主窗口每次启动默认置顶，便于在目标程序获得键盘焦点时查看待输入文本和任务状态。

## 变更前

- 窗口启动时处于普通层级。
- 图钉切换只在当前运行期间保留，最小化与还原保持置顶状态。
- 退出后重新打开恢复普通层级，重复启动已有实例保留当前置顶状态。

## 变更后

- 首次启动及退出后重新打开时，主窗口默认置顶。原生窗口通过 Tauri 的 `alwaysOnTop: true` 创建，首次显示前已采用置顶层级。
- 图钉读取原生窗口状态，置顶时显示蓝色背景和竖直图钉，提示为“取消置顶”。
- 点击图钉可以取消或开启置顶。切换结果只在当前运行期间保留，最小化与还原保持当前状态。
- 重复启动已有实例保留当前置顶状态。退出后重新打开恢复默认置顶。
- 目标程序可以获得键盘焦点，图钉错误提示及任务操作保护遵循 INPUT-REQ-006。

| 输入与操作 | 结果 |
| --- | --- |
| 首次启动 | 主窗口置顶，图钉选中并提示“取消置顶” |
| 点击“取消置顶” | 窗口恢复普通层级，图钉提示“置顶窗口” |
| 普通层级下最小化后重复启动 | 还原已有窗口，保持普通层级 |
| 普通层级下退出后重新打开 | 新窗口默认置顶 |
| 置顶时最小化并还原 | 保持置顶 |
| 普通层级下点击“置顶窗口” | 当前窗口置顶 |
