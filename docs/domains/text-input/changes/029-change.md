# 设置与关于页隐藏滚动条并保留滚动

关联规范：INPUT-REQ-006、[领域设计](../design.md)、[Windows 人工验收](../../../../tests/manual/windows.md)

## 变更原因

设置页、关于页和许可证视图需要隐藏滚动条并保留原生滚动，与历史列表的滚动条显示规则一致。

## 变更前

设置页通过独立内容容器整体滚动。关于页和 MIT 许可证共用内容容器，进入和返回时重设滚动位置并聚焦对应按钮。两个容器均按内容显示滚动条并保留稳定占位。

## 变更后

- 设置页、关于页和 MIT 许可证隐藏滚动条，滚动条占用宽度为零，内容使用全部可用宽度。
- 超出可见高度的内容在各自面板内滚动，保留鼠标滚轮、触控板和现有控件获得焦点后的原生键盘滚动。
- 页面控件的 Tab 顺序、字段错误定位和许可证进入／返回焦点遵循 INPUT-REQ-006。
- 在 600px／320px 宽度及 100%／150% 页面缩放下，内容和控件横向完整，页签切换保持窗口高度。
- 历史列表沿用其隐藏滚动条规则。输入编辑框和历史全文使用各自的滚动样式。
