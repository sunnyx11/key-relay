# 历史摘要序号使用 10px 字号

关联规范：INPUT-REQ-006、[领域设计](../design.md#界面视觉基准)

## 变更原因

历史摘要序号使用 10px 字号，与正文的字号区分。

## 变更前

历史摘要序号与正文均使用 13px 字号。序号使用主题蓝色，正文使用正文颜色。

## 变更后

历史摘要序号使用 10px 字号，正文保持 13px 字号。序号保持主题蓝色，正文保持正文颜色。序号与正文共用字体，位于同一单行预览元素，以一个普通空格分隔，整体遵循超宽省略规则。编号、搜索、查看和恢复按 INPUT-REQ-006 执行。
