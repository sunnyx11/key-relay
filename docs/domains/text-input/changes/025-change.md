# 历史记录展示与管理

关联规范：INPUT-REQ-006、INPUT-REQ-007、[领域设计](../design.md)、[项目架构](../../../project/architecture.md)、[Windows 人工验收](../../../../tests/manual/windows.md)

## 变更原因

历史列表通过单行摘要、持久化置顶、立即删除和统一操作样式提高浏览效率，并保护常用记录。

## 变更前

- 每条历史显示保留换行缩进的两行预览，摘要下方显示时间与 Unicode 字符数，右侧使用文字形式的恢复和删除按钮。点击正文查看全文，独立按钮恢复原文。
- 列表按最近记录顺序及日期分组，无记录置顶功能。
- 历史最多保存 100 条，超限移除最早记录，仅与最近一条相同的原文更新时间。
- 单条删除支持 10 秒撤销；清空经确认后删除全部历史。
- 清空确认区采用透明背景，底部按钮靠右排列。

## 变更后

### 摘要、时间与操作图标

- 正文摘要采用 13px 字号、1.6 行高，仅显示一行。换行按空白展示，超宽显示省略号。完整原文、全文搜索、全文查看与恢复继续有效。
- 时间为独立展示元素，位于正文查看按钮之后、三个操作图标之前，仅显示本地 24 小时制的 `HH:mm`。
- 右侧依次提供置顶、恢复和删除图标按钮。按钮均为 26×26px，间距 4px，采用公共次级按钮的边框、颜色、悬停、焦点及禁用样式。
- 图标使用 16×16px、1px 线宽的 SVG，恢复采用返回箭头，删除采用垃圾桶。按钮提供悬停提示和带记录摘要的可访问名称，SVG 使用 `aria-hidden="true"`。
- 普通图钉倾斜，置顶图钉竖直并显示蓝色及浅蓝背景。`aria-pressed`、可访问名称与提示同步表达置顶状态。
- 常规宽度下摘要、时间及操作图标同排并垂直居中。可视宽度至多 360px 时，摘要占满首行，时间与操作图标在下方靠右排列，空间不足时继续换行。时间保持完整单行，操作按钮保持原尺寸。
- 删除按钮右边缘与“清空历史”按钮右边缘一致。正文查看、置顶、恢复和删除分别接受键盘焦点，沿用各自的动作及禁用保护。

### 置顶、排序与容量

- 每条记录支持置顶和取消置顶。置顶状态保存在 `text.json`；已有记录缺少该字段时视为未置顶。
- 置顶组优先显示，置顶组与普通组均按记录时间倒序排列，时间相同时按记录编号倒序。切换置顶保持记录时间、原文和编号。普通组按今天、昨天和日期分组。
- 列表排序独立于归档顺序，仅与最近归档一条全文完全相同时更新时间并保留置顶状态。
- 置顶计入 100 条上限，新增超限时淘汰最旧的未置顶记录。100 条全部置顶时跳过新增历史，保留全部记录；重复最近归档原文仍可更新时间。
- 历史容量保持全置顶时，输入任务正常执行，标题栏下方的独立容量提示持续显示，并说明取消置顶或删除记录可释放容量。任务消息与结果沿用原状态区。

### 删除与清空确认

- 单条删除立即执行并持久化，适用于置顶及普通记录。删除撤销入口、缓存及动作一并移除。编辑框中的原生撤销重做继续有效。
- 清空针对全局历史，独立于搜索条件。确认框默认保留置顶，提供默认未勾选的“同时删除置顶记录”，显示本次删除数量与保留置顶数量。
- 数量说明、复选框及操作按钮整体置于一个白底、1px 细边框区域中，使用历史记录相同的背景色与边框色，内边距为上下 7px、左右 8px。
- 底部“取消”和“确认”按钮依次靠左排列，间距为 4px，空间不足时换行。初始焦点位于取消按钮，删除数为零时确认按钮禁用。清空成功后聚焦搜索框。
- 单条删除与清空均保留当前编辑及已保存草稿。
- 任务运行、安装、存储初始化及提交期间沿用历史操作保护。保存失败保留内存状态并提供重试。

### 数据与操作示例

| 输入和操作 | 中间状态 | 最终结果 |
| --- | --- | --- |
| 原文为 `第一行\n第二行`，记录时间为本地 13:55 | 摘要显示 `第一行 第二行`，操作图标左侧显示 `13:55` | 常规宽度下整条记录同排，全文查看与恢复保留原始换行 |
| 记录 A 时间 10，B 时间 20；置顶 A | A 的时间保持 10 | 列表 A、B；取消置顶后 B、A |
| 最近归档 B，置顶 A 后再次发送 B | 与最近归档 B 相同 | 更新 B 的时间，保持两条记录和 A 的置顶 |
| 100 条中最旧 A 已置顶、次旧 B 未置顶；新增 C | 保留 A，淘汰 B | 总数 100，C 加入普通组 |
| 100 条全部置顶，发送新文本 C | 历史容量提示保持可见 | 任务正常发送，历史保持原有 100 条 |
| 2 条置顶、3 条普通，搜索仅匹配 1 条；默认确认清空 | 显示删除 3 条、保留置顶 2 条 | 保留全部 2 条置顶，草稿保持原值 |
| 同上，勾选同时删除置顶 | 显示删除 5 条、保留置顶 0 条 | 历史为空，草稿保持原值 |
| 删除一条置顶记录 | 移除并保存 | 删除立即生效，提供的历史动作中无撤销 |
