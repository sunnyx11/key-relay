# B 图标的小尺寸绘制

关联规范：[领域设计](../design.md)

## 变更原因

任务栏中的 B 图标主体偏小，统一缩放的笔画在小尺寸下边缘偏软，需要按输出尺寸设置图形坐标。

## 变更前

B 图标以同一 SVG 缩放生成 16、24、32、48、64、256px 资源，竖笔位置包含半像素坐标。

## 变更后

- 保留浅灰圆角底、蓝色分离式 K 和圆角线端。
- 增大 K 的主体高度与宽度，保留竖笔和斜笔之间的清晰间隙。
- 16、20、24、32、36、40、48、64px 使用各自的坐标与笔画参数，竖笔的直边位于整数像素边界。
- ICO 包含上述八种尺寸及 256px 大图。每张图在目标尺寸绘制，保持透明外部区域。
- 仓库提供图标生成命令，统一生成 SVG 和多尺寸 ICO。
